The standard library written in Prolog (lists.pl, apply.pl, and so on). `library(Name)` is searched in `$MOSA_LIB`, then in the copy of this directory that the build places next to `mosa`, `mosac` and `mosatest`. It also holds the message catalogs `messages_ja.pl` and `messages_en.pl`.

Prolog で書いた標準ライブラリ（lists.pl、apply.pl など）を置く。`library(Name)` は `$MOSA_LIB` を探し、次にビルドが `mosa`、`mosac`、`mosatest` の隣へ写したこのディレクトリを探す。メッセージカタログ `messages_ja.pl` と `messages_en.pl` もここにある。

The standard library written in Prolog (lists.pl, apply.pl, and so on). `library(Name)` is searched in `$MOSA_LIB`, then in the copy of this directory that the build places next to `mosa`, `mosac` and `mosatest`. The modules are added from phase 4 Task 12 on.

Prolog で書いた標準ライブラリ（lists.pl、apply.pl など）を置く。`library(Name)` は `$MOSA_LIB` を探し、次にビルドが `mosa`、`mosac`、`mosatest` の隣へ写したこのディレクトリを探す。モジュールはフェーズ4の Task 12 から足す。

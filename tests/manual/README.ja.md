# マニュアルの例と `mosatest --manual`

このディレクトリには `mosatest --manual` の見本（`good`、`bad-output`、`bad-ids`、`unmarked`。`tests/tests.cmake` で
登録する）を置く。下の規則は `docs/manual/` の章を書く人のためのもの。

```text
mosatest --manual <dir> [--mosa <path>] [--work <dir>]
```

`<dir>` は `en/` と `ja/` を持つ。`--mosa` の既定は動いている `mosatest` の隣の `mosa` で、例の中の `mosac` と
`mosatest` はその `mosa` の隣のもの。`--work` の既定は `tests/tmp/manual`。検査器は失敗ごとに 1 塊（`file:line id`、
期待した出力、実際の出力）を出し、最後に `manual: N checked, M skipped, F failed` を出す（日本語の文面では件数の
1 行も日本語になる）。終了コードは、失敗が無ければ 0、失敗があれば 1、使い方の誤り（`<dir>` に `en/` か `ja/` が
無いときも）は 2。

## 印

`en/*.md` と `ja/*.md` のコードブロックは、`README.md` の中のものを除き、開きの囲いの直前の行に次のどれかを持つ。
印の無いコードブロックは誤りで、コードブロックの直前に無い印も誤り。

| 印 | 意味 |
| --- | --- |
| `<!-- check: ID -->` | 動かして出力を比べる。 |
| `<!-- skip: ID -->` | 動かさない（インストール、OS ごとの手順、検査器が動かせないもの）。 |
| `<!-- file: ID NAME -->` | `prolog` のコードブロックを、章のディレクトリに `NAME`（ディレクトリを含まないファイル名）として書く。 |

`ID` は空白を含まず、1 つのファイルで 1 度だけ使う。章の両版は同じファイル名を持ち、id の並び（印の 3 種すべてを
数える）も同じにする。こうして `en` と `ja` は同じ例を同じ順に見せる。

## `check:` が動かすもの

- 1 行目が `?- ` で始まる `text` のコードブロックは、引数なしの `mosa` を動かす。端末の前の読者と同じ。
- `console` のコードブロックはコマンドの並び。`$ ` で始まる行がコマンドで、期待する出力は次の `$ ` の行までの行
  （空の行も含む）。コマンドは `mosa`、`mosac`、`mosatest` か `./NAME`（章のディレクトリのプログラム。Windows では
  `.exe` を足す）で始める。引数は空白で分け、`'…'` と `"…"` はシェルと同じく語をまとめる。シェルのほかの働き
  （パイプ、リダイレクト、変数、`cd`）は無い。コマンドは順に動き、最初に違ったところでそのコードブロックを止める。
- ほかのコードブロックの `check:` は誤り。

## 入力

既定の入力は、期待する出力のうち `?- ` で始まる行の `?- ` の後ろを、1 行ずつ改行を付けて並べたもの。それ以外
（次の答えを求める `;`、`read/1` が読む入力、複数行の問い合わせ）は印の中に書く。

```text
<!-- check: ID
(X = 1 ; X = 2).
;
-->
```

`<!-- check: ID` と `-->` の間の行が、空の行も含めてそのまま入力になる。`console` のコードブロックでは、どのコマンドも
この入力を受ける。

## 出力の比べ方

どの実行も `LANG=en_US.UTF-8`（`en`）か `LANG=ja_JP.UTF-8`（`ja`）と `MOSA_TRANSCRIPT=1` を受け、`MOSA_LIB`、
`MOSA_HEAP_MAX`、`MOSA_GC_STRESS` は消す。`MOSA_TRANSCRIPT=1` の `mosa` は入力の行を書き返すので、出力は端末に
映るものと同じになる。標準出力と標準エラーは 1 つにまとめる。1 バイトずつ比べる前に、両側の `\r` を除き、入力の
終わりで `mosa` が待っている最後の `?- ` を除く（入力が `halt.` で終わるときは無い）。終了コードは比べない。`;` の
返事の後に `mosa` は空の行を出すので、期待する出力にもそれを書く。実行に時間の上限は無いので、止まらない例は検査
全体を止める。

## ファイル

`file:` のコードブロックは、検査器がそこまで来たときに `<work>/<版>/<章の語幹>/NAME` に書かれ、その章のどの例も
そのディレクトリを作業ディレクトリとして動く。そのディレクトリは章の初めに空にするので、ほかの章や前の回の
ファイルには頼れない。

Prolog programs that the `mosac emit` tests (`emit_test.cmake`; `duplicate.pl` with `library/x.pl` and `mylib/x.pl` checks the duplicate-key diagnostic), the `mosac build` / `mosac run` tests (`build_test.cmake`, with the always-failing compiler `fake_cxx.cpp`), the standalone-executable tests (`standalone_test.cmake`: `raises.pl`, `uses_lists.pl`, `uses_dcg.pl`, `inc.pl` with `a.pl` and `b.pl`, `uses_foo.pl` / `uses_bar.pl` with the `$MOSA_LIB`-style library `mylib/` and its `sub/`, `goal_uses_apply.pl`, `init_uses_apply.pl` and `late_uses_apply.pl`, which name `library(apply)` in a clause body, in an `initialization/1` goal and only in a clause that is never called (the last one makes qualified calls into `apply` and `lists`), `uses_rx.pl` with `rx_mid.pl` (which re-exports `rx_lib.pl`), `takeover_lists.pl` and `takeover_apply.pl` (their own `*_mod.pl` files take over the module of a library they loaded first), and `raises.pl` with `catlib/messages_ja.pl` (a `$MOSA_LIB`-style catalog whose clause body alone loads `library(apply)`), built then run in a directory that holds nothing but the executable, with `MOSA_LIB` unset), the bracket-path test (`bracket_path_test.cmake`: copies `mosac` into a directory whose name holds `]==]`, emits `hello.pl` and configures the result), the installed-layout test (`installed_layout_test.cmake`: `cmake --install` into `tests/tmp/`, then a build with the installed `mosac`; skipped unless the config is Release), the `mosac dist` test (`dist_test.cmake`: packs `hello.pl`, also copied to `こんにちは.pl`, unpacks the archive with `cmake -E tar` and runs the executable in it), the long-list test (`long_list_test.cmake`: it writes a 20000-element list program and compares `mosa` with `mosac run`), the long-atom test (`long_atom_test.cmake`: it writes 70,000-byte names of an atom, a dynamic predicate and a module and compares `mosa` with `mosac run` under `MOSA_WERROR=1`) and the slow `--runtime-source` cache test (`runtime_source_test.cmake`, registered only with `MOSA_SLOW_TESTS=ON`) translate, build and run.

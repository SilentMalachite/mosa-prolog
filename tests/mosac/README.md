Prolog programs that the `mosac emit` tests (`emit_test.cmake`; `duplicate.pl` with `library/x.pl` and `mylib/x.pl` checks the duplicate-key diagnostic), the `mosac build` / `mosac run` tests (`build_test.cmake`, with the always-failing compiler `fake_cxx.cpp`), the standalone-executable tests (`standalone_test.cmake`: `raises.pl`, `uses_lists.pl`, `inc.pl` with `a.pl` and `b.pl`, and `uses_foo.pl` / `uses_bar.pl` with the `$MOSA_LIB`-style library `mylib/` and its `sub/`, built then run in a directory that holds nothing but the executable, with `MOSA_LIB` unset), the installed-layout test (`installed_layout_test.cmake`: `cmake --install` into `tests/tmp/`, then a build with the installed `mosac`; skipped unless the config is Release) and the slow `--runtime-source` cache test (`runtime_source_test.cmake`, registered only with `MOSA_SLOW_TESTS=ON`) translate, build and run.

`mosac emit` のテスト（`emit_test.cmake`。`duplicate.pl` と `library/x.pl`・`mylib/x.pl` は鍵の重なりの診断を見る）、`mosac build` / `mosac run` のテスト（`build_test.cmake`。必ず失敗するコンパイラ `fake_cxx.cpp` を使う）、単独の実行ファイルのテスト（`standalone_test.cmake`。`raises.pl`、`uses_lists.pl`、`inc.pl` と `a.pl`・`b.pl`、`uses_foo.pl`・`uses_bar.pl` と `$MOSA_LIB` 風のライブラリ `mylib/` とその `sub/` を作ってから、実行ファイルしか無いディレクトリで `MOSA_LIB` を外して動かす）、インストールの形のテスト（`installed_layout_test.cmake`。`tests/tmp/` に `cmake --install` し、入れた `mosac` でビルドする。構成が Release でなければ飛ばす）、遅い `--runtime-source` のキャッシュのテスト（`runtime_source_test.cmake`。`MOSA_SLOW_TESTS=ON` のときだけ登録する）が翻訳し、ビルドして動かす Prolog のプログラムを置く。

Prolog programs that the `mosac emit` tests (`emit_test.cmake`), the `mosac build` / `mosac run` tests (`build_test.cmake`, with the always-failing compiler `fake_cxx.cpp`), the standalone-executable tests (`standalone_test.cmake`: `raises.pl`, `uses_lists.pl`, `inc.pl` with `a.pl` and `b.pl`, built then run in a directory that holds nothing but the executable, with `MOSA_LIB` unset) and the installed-layout test (`installed_layout_test.cmake`: `cmake --install` into `tests/tmp/`, then a build with the installed `mosac`) translate, build and run.

`mosac emit` のテスト（`emit_test.cmake`）、`mosac build` / `mosac run` のテスト（`build_test.cmake`。必ず失敗するコンパイラ `fake_cxx.cpp` を使う）、単独の実行ファイルのテスト（`standalone_test.cmake`。`raises.pl`、`uses_lists.pl`、`inc.pl` と `a.pl`・`b.pl` を作ってから、実行ファイルしか無いディレクトリで `MOSA_LIB` を外して動かす）、インストールの形のテスト（`installed_layout_test.cmake`。`tests/tmp/` に `cmake --install` し、入れた `mosac` でビルドする）が翻訳し、ビルドして動かす Prolog のプログラムを置く。

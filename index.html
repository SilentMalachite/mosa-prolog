日本語で規則を書いて、答えを尋ねる Prolog

Mosa Prolog は、プログラミング言語 Prolog を動かすソフトウェア（処理系）です。Prolog では、手順ではなく「何が成り立つか」を書きます。事実と規則を書いておいて問い合わせると、Mosa が規則をたどって答えを探します。名前に日本語を使えるので、書いた規則をそのまま日本語として読めます。

最新版をダウンロード マニュアルを読む

このページは 0.5.1（2026 年 11 月 24 日公開）に合わせて書いています。0.5.1 は、2 度のコードレビューで見つかった点を直した保守のリリースです。変更点はリリースノートにあります。macOS、Linux、Windows で動き、Apache-2.0 ライセンスで配布しています。

Prolog は、尋ねると答えを探す言語です

ふつうのプログラムは「こうして、次にこうする」と手順を書きます。Prolog では、成り立つこと（事実）と、そこから言えること（規則）を書きます。あとは問い合わせをすれば、どうやって答えを探すかは Prolog が受け持ちます。

問い合わせが成り立てば true.、成り立たせる方法が見つからなければ false. が返ります。答えが見つからないときに、それらしい答えをこしらえることはありません。

大文字か下線で始まる名前（X など）は変数です。変数を入れて尋ねると、成り立つ値を探して見せます。答えが複数あるときは、; を打つたびに次の答えが出ます。

Prolog が向いているのは、たとえば次のような仕事です。

  • 判断の決まりごとを、規則として書き出せる
  • 間違えたときの損が大きく、なぜそうなったかを説明する必要がある
  • たくさんの組み合わせの中から、条件に合うものを探す

大量のデータを集計するのが中心なら、SQL などのほうが向いています。

事実をそのまま尋ねる
?- 親(太郎, 花子).
true.
?- 親(花子, 太郎).
false.
変数を入れて尋ねる
?- 親(太郎, X).
X = 一郎;

X = 花子.
?- 親(X, 三郎).
X = 次郎.

入っているコマンドは 3 つです

ダウンロードしたパッケージの bin フォルダに入っています。はじめは mosa だけを使えば十分です。

mosa

対話しながら動かす

?- のプロンプトに問い合わせを打つか、ファイルを読み込んで動かします。ほかに入れるものはありません。trace と打てば、デバッガでゴールの動きを 1 歩ずつ追えます。

$ mosa 家族.pl

mosac

実行ファイルを作る

Prolog のプログラムを C++ に訳してコンパイルし、Mosa の入っていないコンピュータでも動く 1 つのファイルにします。

$ mosac build app.pl -o app

mosatest

テストを動かす

Prolog で書いたテストを流します。--diff を付けると、mosa と mosac が同じ答えを返すかを比べます。

$ mosatest tests/pl/

日本語のままで書けます

Mosa は文字を UTF-8 で読み書きします。原子（太郎 のような、ものの名前）、述語（親 のような、関係の名前）、変数に日本語を使えて、エラーや警告も日本語で出ます。

変数は下線から始める

日本語には大文字と小文字の区別がないので、太郎 は原子になります。日本語名の変数は _太郎 のように下線で始めます。

?- 名前 = 太郎.
false.
?- _名前 = 太郎.
_名前 = 太郎.
家系.pl
親(太郎, 一郎).
親(一郎, 花子).
祖父母(_祖, _孫) :- 親(_祖, _親), 親(_親, _孫).
$ mosa 家系.pl -g "祖父母(X, 花子)." -t halt
X = 太郎.

1 字は 1 字として数える

文字は Unicode の 1 文字を 1 字として数えます。「𠮷」のような、コンピュータで扱いにくい字も 1 字です。

?- atom_length(東京, N).
N = 2.
?- atom_length('𠮷野家', N).
N = 3.
?- atom_chars(日本語, L).
L = [日,本,語].

全角の記号でも書ける

日本語入力をオンにしたまま打つと、（ や 、 や 。 が入ります。ふだんの Mosa はこれを読みませんが、フラグ japanese_punctuation を true にすると、全角の記号を半角として読みます。かぎかっこ 「」 は単一引用符として働きます。

?- X = 親（子）。
構文エラー: 行 1 列 6: 予期しないトークン （
?- set_prolog_flag(japanese_punctuation, true).
true.
?- X = 親（太郎、一郎）。
X = 親(太郎,一郎).
?- X = 「東 京」。
X = '東 京'.

ファイルを全角の記号で書く

1 行目のディレクティブで、そのファイルの終わりまで全角記号モードになります。この行だけは半角で書きます。

首都.pl
:- set_prolog_flag(japanese_punctuation, true).

首都（日本、東京）。
首都（フランス、パリ）。
首都（アメリカ、「ワシントン D.C.」）。
?- consult('首都.pl').
true.
?- 首都(X, Y).
X = 日本, Y = 東京;

X = フランス, Y = パリ;

X = アメリカ, Y = 'ワシントン D.C.'.

メッセージの言語は、環境変数 LANG が ja で始まっていれば日本語、それ以外なら英語になります。フラグ message_language でも切り替えられます。詳しくはマニュアル第 11 章にあります。

書いたプログラムを、1 つの実行ファイルにして渡せます

mosac は Prolog のプログラムを C++ に訳し、コンパイラを呼んで実行ファイルを作ります。できたファイルは、Mosa も Prolog のファイルもコンパイラも無いコンピュータで動きます。規則を、判定のための小さな道具として配れます。

C++ のコンパイラが要るのは、mosac で実行ファイルを作るときだけです。macOS では Xcode Command Line Tools、Linux では g++、Windows では Build Tools for Visual Studio 2022 を使います。

速さの目安として、7 本のプログラムで測った記録があります。変換した実行ファイルは、インタプリタの 1.0〜26.6 倍の速さで動きました（Apple M1 Max、2026 年 11 月の測定。ベンチマークの記録）。

こんにちは.pl
:- initialization(main, main).
main :- write(こんにちは), nl.
$ mosac build こんにちは.pl -o こんにちは
$ ./こんにちは
こんにちは

1 行目の initialization(main, main) は、読み込んだら main を動かして終わる、という指示です。手順はマニュアル第 13 章にあります。

どこまで正しく動くかを、数字で公開しています

Prolog には国際規格 ISO/IEC 13211-1 があります。Mosa はこの規格に沿って作り、どこまで合っているかをテストで測って公開しています。テストは macOS、Linux、Windows の CI で、変更のたびに流しています。

0.5.1（2026 年 11 月 24 日）時点の記録
確かめていること結果測り方
ISO 規格どおりに動くか 98.4%2333 件中 2295 件が合格 同梱した Logtalk の準拠スイートを mosatest --suite で流す（不合格の一覧）
規格の外のライブラリ述語（format/2 など） 99.2%605 件中 600 件が合格 同じスイートの別の欄で数え、ISO の率には混ぜない
mosa と mosac が同じ答えを返すか 違い 07298 行を 1 バイトずつ比べた mosatest --diff で、答え、エラー、出力を比べる（一致の記録）
マニュアルの例がそのとおりに動くか すべて確認日本語版と英語版 mosatest --manual で流す。インストールの手順のように機械で変わる例だけは除く

あとから変えにくい設計は、実装する前に設計の決定記録（ADR）に書いています。0.5.1 の時点で 30 件です。まだできないことは CHANGELOG の「既知の制限」にまとめています。

LLM が下書きした規則を、人が読んで確かめる

LLM は文章を扱うのが得意ですが、同じ質問に毎回同じ答えを返すとは限らず、答えの根拠をたどるのも難しい道具です。Prolog は書かれた規則を毎回同じように動かし、規則から言えないことには false を返します。この 2 つは分担できます。

  1. LLM が規則の下書きを書く文章で書かれた決まりごとを、Prolog の事実と規則にする。
  2. 人が日本語の規則を読んで直す規則が日本語で書かれていれば、その分野の専門家がそのまま読める。
  3. Mosa が規則どおりに判定する同じ入力には同じ答え。mosac で実行ファイルにすれば、判定器として配れる。
地層の上下の記録を調べる規則
直接上位(a層, b層).
直接上位(b層, c層).

より上(A, B) :- 直接上位(A, B).
より上(A, B) :- 直接上位(A, C), より上(C, B).

矛盾 :- より上(X, X).  % 自分より上にある層があれば記録の矛盾

Prolog が請け合えるのは「書いた規則どおりに答える」ことまでです。規則そのものが間違っていれば、答えも間違います。だからこそ、規則を人が読める形で残します。

この考え方は、作者の記事「Prologは死んだのか？ ― LLM時代における論理プログラミングの現在地」に詳しく書いています。

入れて、最初の問い合わせをするまで

ビルド済みのパッケージを展開して、シェルから呼べるようにします。mosa を動かすのに、ほかに入れるものはありません。

macOS
macOS 26 以降（Apple Silicon）
Linux
x86_64。glibc が Ubuntu 24.04 と同じか、それより新しいもの
Windows
Windows 10 22H2 以降と Windows 11（x64）。Smart App Control が無効のもの
注意
パッケージには署名がありません。OS が起動を止めたときの進め方はマニュアル第 2 章にあります。

  1. パッケージをダウンロードする

    自分のコンピュータに合うパッケージをダウンロードします。下のファイル名を押すと、0.5.1 のパッケージを直接ダウンロードできます。このあとのコマンドも 0.5.1 のものです。もっと新しい版が出ていたら、Releases のページから落として、版の番号を読み替えてください。

    コンピュータパッケージ
    macOS（Apple Silicon）mosa-0.5.1-macos-arm64.tar.gz
    Linux（x86_64）mosa-0.5.1-linux-x86_64.tar.gz
    Windows（x64）mosa-0.5.1-windows-x86_64.zip

  2. ホームフォルダに展開する

    パッケージが「ダウンロード」フォルダにあるものとして書いています。

    macOS（ターミナル）
    ターミナル
    $ cd ~
$ tar -xzf ~/Downloads/mosa-0.5.1-macos-arm64.tar.gz
    Linux（端末）
    端末
    $ cd ~
$ tar -xzf ~/Downloads/mosa-0.5.1-linux-x86_64.tar.gz
    Windows（PowerShell）
    PowerShell
    Expand-Archive "$HOME\Downloads\mosa-0.5.1-windows-x86_64.zip" -DestinationPath $HOME

  3. 隔離の印を外す（macOS のみ）

    macOS は、ブラウザでダウンロードしたファイルに隔離の印を付け、署名のないプログラムを開きません。次のコマンドで、フォルダとその中のすべてのファイルから印を外します。

    ターミナル
    $ xattr -dr com.apple.quarantine ~/mosa-0.5.1-macos-arm64

  4. bin フォルダを PATH に加える

    PATH は、コマンドの名前を打ったときにシェルが探すフォルダの一覧です。設定は、新しく開いたウィンドウから効きます。

    macOS（zsh）
    ターミナル（zsh）
    $ echo 'export PATH="$HOME/mosa-0.5.1-macos-arm64/bin:$PATH"' >> ~/.zshrc
    Linux（bash）
    端末（bash）
    $ echo 'export PATH="$HOME/mosa-0.5.1-linux-x86_64/bin:$PATH"' >> ~/.bashrc
    Windows（PowerShell）
    PowerShell（1 行ずつ打つ）
    $bin = "$HOME\mosa-0.5.1-windows-x86_64\bin"
$old = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$old;$bin", "User")

  5. Mosa が見つかるか確かめる

    新しいウィンドウを開いて、mosa --version と打ちます。版の番号が出れば準備はできています。

    シェル
    $ mosa --version
mosa 0.5.1

  6. 最初の問い合わせをする

    mosa と打つと、プロンプト ?- が出ます。問い合わせを 1 つずつ打って Enter を押します。問い合わせはどれもピリオドで終わります。halt. で終わります。

    $ mosa
?- X = こんにちは.
X = こんにちは.
?- atom_length(こんにちは, N).
N = 5.
?- halt.

    Windows のコンソールのウィンドウで日本語を打つことは、まだ確かめていません（既知の制限）。うまく打てないときは、日本語をファイルに書いて読み込んでください。

うまくいかないときは、マニュアル第 2 章「入手と起動」を見てください。macOS が「検証できません」と止めたとき、Windows に青い保護の画面が出たとき、mosa が見つからないときの進め方を書いています。

OS-dependent code. OS branches go nowhere else. `terminal.cpp` tells whether standard input is a terminal, `exe_path.cpp` finds the running executable and reads environment variables, and `console.cpp` sets the Windows console to UTF-8, puts the standard streams of Windows in binary mode, and is the one byte source for standard input (a Windows console is read as UTF-16 with `ReadConsoleW`), and `command_line.cpp` hands the command-line arguments over as UTF-8 (on Windows they are rebuilt from the UTF-16 command line with `CommandLineToArgvW`), and `process.cpp` starts a child process and waits for its exit code (`posix_spawnp`, or `CreateProcessW` on Windows), and `toolchain.cpp` finds the C++ compiler and CMake for `mosac` (on Windows it asks `vswhere` for MSVC and captures the environment that `vcvarsall.bat` sets), and `parse_double.cpp` reads the spelling of a floating-point number into a `double` (on Apple with `strtod_l` in the C locale, because floating-point `std::from_chars` needs macOS 26.0 and the release targets macOS 14; elsewhere with `std::from_chars`).

OS 依存コードを置く。ここ以外に OS 分岐を書かない。`terminal.cpp` は標準入力が端末かを判定し、`exe_path.cpp` は動いている実行ファイルの場所と環境変数を読み、`console.cpp` は Windows のコンソールを UTF-8 にし、Windows の標準の流れを binary にして、標準入力のただ一つの読み取り口になる（Windows のコンソールは `ReadConsoleW` で UTF-16 として読む）。`command_line.cpp` はコマンドラインの引数を UTF-8 で渡す（Windows では UTF-16 のコマンドラインから `CommandLineToArgvW` で作り直す）。`process.cpp` は子プロセスを起こして終了コードを待つ（`posix_spawnp`、Windows では `CreateProcessW`）。`toolchain.cpp` は `mosac` の使う C++ コンパイラと CMake を探す（Windows では `vswhere` で MSVC を見つけ、`vcvarsall.bat` が設定する環境を取る）。`parse_double.cpp` は浮動小数点数の綴りを `double` にする（浮動小数点の `std::from_chars` は macOS 26.0 からで、リリースは macOS 14 を対象にするので、Apple では C ロケールの `strtod_l` で読む。ほかの OS は `std::from_chars` で読む）。

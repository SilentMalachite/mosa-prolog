Module names, `current_module/1`, `use_module/1` and `use_module/2`, `Module:Goal`, and `meta_predicate/1`. `library(Name)` searches `$MOSA_LIB`, then `lib/Name.pl` beside the executable. A `:- use_module` directive imports into the module being loaded. An atom that names a loaded module selects that module. `multifile(Module:PI)` declares that module, and a qualified clause for a declared predicate is added there. `op/3` affects the module that executes it. Operators declared in `user` are visible in every module. An `op/3` term in an export list becomes visible to a module that imports that export.

モジュール名、`current_module/1`、`use_module/1` と `use_module/2`、`Module:Goal`、`meta_predicate/1`。`library(Name)` は `$MOSA_LIB`、次に実行ファイルの隣の `lib/Name.pl` を探す。`:- use_module` は読み込み中のモジュールへ取り込む。載っているモジュールの原子はそのモジュールを指す。`multifile(Module:PI)` はそのモジュールを宣言し、宣言済みの修飾した節はそこへ足す。`op/3` は実行したモジュールに効く。`user` の演算子はどのモジュールからも見える。公開リストの `op/3` は、それを取り込んだモジュールから見える。

# 5. 項と単一化

この章では、Prolog が扱うデータである項（こう）の種類を知り、`=` が 2 つの項をどうやって同じにするかを覚えます。

## 手順

1. ターミナル（Linux では端末、Windows では PowerShell）を開き、第 4 章の `cd` の行でフォルダ `prolog` に移って、`mosa` を起動します。`X` に数を入れてみます。数も項の一つです。`42` や `-7` は整数です。`3.14` のように小数点のある数は浮動小数点数です。

<!-- check: numbers -->
```text
?- X = 42.
X = 42.
?- X = -7.
X = -7.
?- X = 3.14.
X = 3.14.
```

2. 原子を単一引用符で囲んで書きます。第 3 章の原子は、漢字やかな、アルファベットの小文字で始まる名前でした。単一引用符で囲むと、空白やピリオドを含む名前や、アルファベットの大文字で始まる名前も原子になります。第 4 章の `'家族.pl'` がその例です。Mosa は、引用符が要る原子にだけ引用符を付けて出します。ですから、`'こんにちは'` と `こんにちは` は同じ原子です。

<!-- check: quoted -->
```text
?- X = 'こんにちは 世界'.
X = 'こんにちは 世界'.
?- 'こんにちは' = こんにちは.
true.
```

3. 複合項を作ります。複合項は、名前の後のかっこの中に引数を並べたもので、第 4 章の事実と同じ形をしています。`点(1, 2)` の名前は `点`、引数は `1` と `2` です。ここでの `点(1, 2)` は問いではなく、ただのデータです。Mosa はそれを `X` に入れます。Mosa は、コンマの後に空白を入れずに書きます。

<!-- check: compound -->
```text
?- X = 点(1, 2).
X = 点(1,2).
```

4. 組み込みの述語を 2 つ使って、複合項を分解します。`functor/3` は名前と引数の数を、`arg/3` は 1 から数えて何番目かの引数を返します。引数の数をアリティと呼びます。名前とアリティの組を、その項の関数子と呼び、`点/2` のように書きます。`atom_length/2` の書き方と同じです。

<!-- check: functor-arg -->
```text
?- functor(点(1, 2), N, A).
N = 点, A = 2.
?- arg(2, 点(1, 2), X).
X = 2.
```

5. 2 つの複合項を同じにします。`=` は、左右が同じ項になるような変数の値を探します。これを単一化と呼びます。`点(1, Y) = 点(X, 2)` は左右とも関数子が `点/2` なので、Mosa は引数を 1 組ずつ単一化します。`1` と `X`、次に `Y` と `2` です。Mosa は、問い合わせに先に出てきた変数から順に答えるので、`Y` が先に出ます。

<!-- check: unify -->
```text
?- 点(1, Y) = 点(X, 2).
Y = 2, X = 1.
```

6. 単一化できない項を試します。2 つの複合項が単一化できるのは、関数子が同じで、引数がどの組も単一化できるときだけです。名前やアリティが違えば `false.` になります。同じ変数が 2 か所にあれば、両方で同じ値にならなければなりません。`X` が `1` と `2` の両方になることはできません。整数と浮動小数点数は、数として等しくても別の項です。

<!-- check: no-unify -->
```text
?- 点(1, 2) = 線(1, 2).
false.
?- 点(1, 2) = 点(1, 2, 3).
false.
?- 点(X, X) = 点(1, 2).
false.
?- 1 = 1.0.
false.
```

7. 項の中に項を入れます。引数が複合項でもかまいません。Mosa は中の項も同じように単一化します。

<!-- check: nested -->
```text
?- 日付(2026, 月(11), D) = 日付(Y, M, 8).
D = 8, Y = 2026, M = 月(11).
```

8. 変数どうしを単一化します。`X = Y` の後、2 つの変数は同じ値を表します。その値がまだ分かっていなくてもかまいません。Mosa は `X = Y.` と答えます。どちらかに値が入ると、もう一方も同じ値になります。

<!-- check: two-variables -->
```text
?- X = Y.
X = Y.
?- X = Y, Y = こんにちは.
X = こんにちは, Y = こんにちは.
```

9. 問い合わせのほかの変数を含む値を見ます。Mosa はその変数を名前で書き、変数の値は別に示します。ですから、下の答えは「`X` は `箱(2)`」と読みます。

<!-- check: named-inside -->
```text
?- X = 箱(Y), Y = 2.
X = 箱(Y), Y = 2.
```

10. 匿名変数 `_` を使います。`_` は「ここには何かの項があるが、その値は要らない」という意味です。`_` は 1 つ 1 つが別の新しい変数で、Mosa は答えに出しません。名前のない変数が値の中にあると、Mosa は `_G1` のように `_G` で始まる名前を付けて出します。第 3 章の警告にあった `_G1` もこれです。

<!-- check: anonymous -->
```text
?- 点(X, _) = 点(1, 2).
X = 1.
?- X = 点(1, _).
X = 点(1,_G1).
```

11. 事実の中で複合項を使います。第 4 章で `家族.pl` を作ったのと同じように、フォルダ `prolog` に `住む.pl` というファイルを作ります。1 つ 1 つの事実は、ある人がどこに住んでいるかを、都市と国の組の住所で表します。

<!-- file: lives-file 住む.pl -->
```prolog
住む(太郎, 住所(東京, 日本)).
住む(花子, 住所(パリ, フランス)).
住む(一郎, 住所(大阪, 日本)).
```

12. ファイルを読み込み、都市はどこでもよいので日本に住んでいるのは誰かを尋ねます。最初の答えの後で `;` を打ちます。次に、花子がどの都市に住んでいるかを尋ねます。

<!-- check: lives
consult('住む.pl').
住む(X, 住所(_, 日本)).
;
住む(花子, 住所(X, _)).
-->
```text
?- consult('住む.pl').
true.
?- 住む(X, 住所(_, 日本)).
X = 太郎;

X = 一郎.
?- 住む(花子, 住所(X, _)).
X = パリ.
```

13. `halt.` と打って終わります。

## 何が起きたか

Prolog のプログラムが扱うものは、どれも項です。項には次の 4 種類があります。

- 数。`42` や `-7` のような整数と、`3.14` のような浮動小数点数があります。
- 原子。`こんにちは` のように漢字やかな、アルファベットの小文字で始まる名前と、`'こんにちは 世界'` のように単一引用符で囲んだものです。
- 変数。`X` のようにアルファベットの大文字で始まる名前と、`_` で始まる名前です。
- 複合項。`点(1, 2)` のように、名前の後のかっこの中に引数を並べたものです。引数もまた項です。`点(1, 2)` の関数子は、名前とアリティの組 `点/2` です。

`=` は、次の決まりで左右を単一化します。

- まだ値のない変数は、どんな項とも単一化でき、その項を値にします。
- 原子は同じ原子とだけ、数は同じ数とだけ単一化できます。`1` と `1.0` は単一化できません。
- 2 つの複合項は、関数子が同じで、引数を左から 1 組ずつ単一化できるときに単一化できます。

1 組でも単一化できなければ全体が失敗し、Mosa は `false.` と答えます。

Mosa は `=` に限らず、どの問い合わせに答えるときも単一化を使います。第 4 章の事実も、問い合わせ `親(太郎, X)` も複合項です。Mosa は問い合わせを事実と順に単一化します。`親(太郎, 一郎)` と単一化すると `X = 一郎` になります。手順 12 では、`住む(X, 住所(_, 日本))` は 1 つ目と 3 つ目の事実と単一化できました。2 つ目の事実とは単一化できません。`フランス` と `日本` は別の原子だからです。

Mosa は答えの中に、問い合わせの変数のうち値のあるものを、問い合わせに先に出てきた順に示します。値の中にある問い合わせの変数は名前で書き（`X = 箱(Y)`）、名前のない変数は `_G1`、`_G2` のように書きます。

## 練習問題

1. `f(X, b) = f(a, Y)` に、Mosa はどう答えますか。`f(X, X) = f(a, a)` ではどうですか。
2. `住む.pl` を使って、パリに住んでいるのは誰かを尋ねてください。

### 答え

1. 1 つ目では、`X` が `a` と、`b` が `Y` と単一化されます。2 つ目では、1 組目で `X = a` になります。すると 2 組目は `a = a` になり、これは成り立ちます。

<!-- check: exercise-unify -->
```text
?- f(X, b) = f(a, Y).
X = a, Y = b.
?- f(X, X) = f(a, a).
X = a.
```

2. 都市に `パリ` を入れ、国は `_` にしておきます。

<!-- check: exercise-paris -->
```text
?- consult('住む.pl').
true.
?- 住む(X, 住所(パリ, _)).
X = 花子.
```

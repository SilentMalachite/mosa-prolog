# 6. 算術

この章では、`is/2` で数を計算し、数を比べ、規則の中で計算を使います。

## 手順

1. 第 4 章の `cd` の行でフォルダ `prolog` に移り、`mosa` を起動します。`X` を足し算と単一化してみます。`=` は何も計算しません。`1 + 2` は、名前が `+` で引数が `1` と `2` の複合項で、関数子は `+/2` です。`+` のように 2 つの引数の間に書く名前を、演算子と呼びます。Mosa は演算子を単独で書くとき、`(+)` のようにかっこで囲みます。

<!-- check: not-computed -->
```text
?- X = 1 + 2.
X = 1+2.
?- X = 1 + 2, functor(X, N, A).
X = 1+2, N = (+), A = 2.
```

2. `is/2` で計算します。`X is 1 + 2` は、右辺の値を計算してから、その値と左辺を単一化します。式の値を計算することを評価と呼び、`is/2` がする評価を算術評価と呼びます。`*` は掛け算です。`-` は左から順に引くので、`10 - 4 - 3` は `(10 - 4) - 3` です。

<!-- check: is -->
```text
?- X is 1 + 2.
X = 3.
?- X is 7 * 6.
X = 42.
?- X is 10 - 4 - 3.
X = 3.
```

3. 割り算をします。`/` の答えは、割り切れるときでも、いつも浮動小数点数です。`//` は整数どうしを割って小数部分を捨て、`mod` は余りを返します。

<!-- check: divide -->
```text
?- X is 7 / 2.
X = 3.5.
?- X is 8 / 2.
X = 4.0.
?- X is 7 // 2.
X = 3.
?- X is 7 mod 2.
X = 1.
```

4. 計算の順に気を付けます。学校の算数と同じように、`*`、`/`、`//`、`mod` は `+` や `-` より先に計算します。順を変えるときは、かっこを使います。

<!-- check: order -->
```text
?- X is 1 + 2 * 3.
X = 7.
?- X is (1 + 2) * 3.
X = 9.
```

5. 算術の関数を使います。`is/2` の右辺では、`max(A, B)` は 2 つの数の大きい方、`abs(A)` は絶対値、`sqrt(A)` は平方根です。平方根はいつも浮動小数点数になります。

<!-- check: functions -->
```text
?- X is max(3, 8).
X = 8.
?- X is abs(-5).
X = 5.
?- X is sqrt(2).
X = 1.4142135623730951.
```

6. 計算の結果を次のゴールで使います。`X` の値が `3` になった後なら、`X * 10` を評価できます。

<!-- check: chain -->
```text
?- X is 1 + 2, Y is X * 10.
X = 3, Y = 30.
```

7. 数を比べます。`<`（より小さい）、`>`（より大きい）、`=<`（以下）、`>=`（以上）、`=:=`（等しい）、`=\=`（等しくない）は、左右を評価してから値を比べます。評価しない `=` と比べてみてください。`1 + 2` と `3` は別の項ですが、値は同じです。`=:=` は値を比べるので、整数 `2` と浮動小数点数 `2.0` は等しくなります。

<!-- check: compare -->
```text
?- 3 < 5.
true.
?- 5 < 3.
false.
?- 3 =< 3.
true.
?- 1 + 2 =:= 3.
true.
?- 1 + 2 = 3.
false.
?- 2 =:= 2.0.
true.
```

8. よくある間違いを、わざとしてみます。「以下」は `=<` です。`<=` と打つと、Mosa は問い合わせを読めず、読むのをやめた列を出します。また、Mosa が `is/2` の右辺を評価するときには、右辺の変数に値が入っていなければなりません。ゴールは左から順に実行されるので、下の 2 つ目の問い合わせでは、`Y is X * 2` を実行するときに `X` にまだ値がありません。このとき Mosa は `instantiation_error` を含む警告を出します。値が要るところに、値のない変数があったという意味です。警告の読み方は第 9 章で説明します。`X = 3` を先に書けば、問い合わせは成り立ちます。

<!-- check: mistakes -->
```text
?- 3 <= 5.
構文エラー: 行 1 列 3: 予期しないトークン <=
?- Y is X * 2, X = 3.
警告: ゴールは例外を送出しました: error(instantiation_error,context((is)/2,_G1))
?- X = 3, Y is X * 2.
X = 3, Y = 6.
```

9. 規則の中で計算を使います。フォルダ `prolog` に `店.pl` というファイルを作り、次の行を書きます。事実は品物 1 つの値段を表します。規則は「`X` の値段が `P` で、`T` が `P * N` なら、`X` を `N` 個買ったときの代金は `T` である」と言っています。

<!-- file: shop-file 店.pl -->
```prolog
値段(りんご, 120).
値段(パン, 250).
値段(牛乳, 180).

代金(X, N, T) :- 値段(X, P), T is P * N.
```

10. ファイルを読み込み、りんご 3 個の代金を尋ねます。次に、2 個買って代金が 400 より小さい品物はどれかを尋ね、最初の答えの後で `;` を打ちます。

<!-- check: shop
consult('店.pl').
代金(りんご, 3, T).
代金(X, 2, T), T < 400.
;
-->
```text
?- consult('店.pl').
true.
?- 代金(りんご, 3, T).
T = 360.
?- 代金(X, 2, T), T < 400.
X = りんご, T = 240;

X = 牛乳, T = 360.
```

11. `halt.` と打って終わります。

## 何が起きたか

`is/2` と比較の述語は、算術式を評価します。算術式は、数か、または数を `+`、`-`、`*`、`/`、`//`、`mod` のような演算子や、`max`、`abs`、`sqrt` のような関数で組み立てた複合項です。数の代わりに変数を書くこともできますが、式を評価するときまでに、その変数に値が入っていなければなりません。ほかの場所では、手順 1 のように、`1 + 2` はただの複合項です。

`is/2` が評価するのは右辺だけで、その後で単一化します。ですから、`3 is 1 + 2` は成り立ちますが、`1 + 2 is 3` は成り立ちません。値の `3` は、項の `1 + 2` と単一化できないからです。

<!-- check: is-one-side -->
```text
?- 3 is 1 + 2.
true.
?- 1 + 2 is 3.
false.
```

手順 10 では、Mosa は第 4 章と同じように、`値段(X, P)` を事実と順に試しました。`りんご` の代金は `240` で、`400` より小さいので、これが 1 つ目の答えです。`パン` の代金は `500` なので `T < 400` が失敗し、Mosa は次の事実までバックトラックしました。`牛乳` の代金は `360` です。`牛乳` は最後の事実なので、Mosa はもう試すものがないことを知っていて、答えの後にピリオドを付けました。

数には限りがあります。整数は -9223372036854775808 から 9223372036854775807 までで、結果がこの範囲を超えると `int_overflow` を含む警告が出ます。浮動小数点数は 2 進数で、有効数字およそ 16 桁で表します。そのため `0.1` のような 10 進数の小数はぴったりには表せず、足し算の結果にわずかなずれが見えることがあります。

<!-- check: limits -->
```text
?- X is 9223372036854775807 + 1.
警告: ゴールは例外を送出しました: error(evaluation_error(int_overflow),context((is)/2,_G1))
?- X is 0.1 + 0.2.
X = 0.30000000000000004.
```

## 練習問題

1. 1 日は何秒ですか。`24 * 60 * 60` を Mosa に計算させてください。
2. `店.pl` に規則 `安い/1` を書き足し、`X` の値段が 200 より小さいときに `安い(X)` が成り立つようにしてください。それから、安い品物をすべて尋ねてください。

### 答え

1. 86400 秒です。

<!-- check: exercise-seconds -->
```text
?- X is 24 * 60 * 60.
X = 86400.
```

2. 値段を調べてから比べます。`店.pl` の最後に、次の規則を書き足します。

<!-- file: shop-cheap 店.pl -->
```prolog
値段(りんご, 120).
値段(パン, 250).
値段(牛乳, 180).

代金(X, N, T) :- 値段(X, P), T is P * N.

安い(X) :- 値段(X, P), P < 200.
```

それから、もう一度読み込んで尋ね、`;` を 1 回打ちます。

<!-- check: exercise-cheap
consult('店.pl').
安い(X).
;
-->
```text
?- consult('店.pl').
true.
?- 安い(X).
X = りんご;

X = 牛乳.
```

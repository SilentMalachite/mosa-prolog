# 8. 制御

この章では、Mosa の探し方を操ります。ゴールを否定し、if-then-else で 2 つのゴールのどちらかを選び、残った選択肢をカットで捨て、すべての答えを 1 つのリストに集めます。

## 手順

1. 第 4 章の `cd` の行でフォルダ `prolog` に移り、`mosa` を起動します。いちばん簡単な 2 つのゴールを試します。`true` は必ず成功し、`fail` は必ず失敗します。

<!-- check: true-fail -->
```text
?- true.
true.
?- fail.
false.
```

2. フォルダ `prolog` に `家族.pl` というファイルを作ります。第 4 章の事実と、1 人ごとの事実 `人/1` と、規則を 1 つ書きます。`\+` は「でない」と読みます。`\+ 親(X, _)` は、Mosa が `X` の子を 1 人も見つけられないときに成り立ちます。ですから、この規則は「`X` が人で、Mosa が `X` の子を見つけられないなら、`X` には子がいない」と言っています。

<!-- file: family-file 家族.pl -->
```prolog
親(太郎, 一郎).
親(太郎, 花子).
親(一郎, 桃子).
親(一郎, 次郎).
親(次郎, 三郎).

人(太郎).
人(一郎).
人(花子).
人(桃子).
人(次郎).
人(三郎).

子がいない(X) :- 人(X), \+ 親(X, _).
```

3. ファイルを読み込み、花子に子がいないかどうか、太郎に子がいないかどうかを尋ねます。それから、子がいないのは誰かを、ピリオドが出るまで `;` を打ちながら尋ねます。

<!-- check: not
consult('家族.pl').
\+ 親(花子, _).
\+ 親(太郎, _).
子がいない(X).
;
;
-->
```text
?- consult('家族.pl').
true.
?- \+ 親(花子, _).
true.
?- \+ 親(太郎, _).
false.
?- 子がいない(X).
X = 花子;

X = 桃子;

X = 三郎.
```

4. ゴールの順を入れ替えると、問い合わせが失敗することを確かめます。`\+` は変数に値を入れません。ここでは `X` にまだ値がないので、`親(X, _)` は `太郎` などの `X` で成り立ち、`\+ 親(X, _)` はすぐに失敗します。`\+` は、その変数に値を入れるゴールの後に書きます。手順 2 の規則もそう書いています。

<!-- check: not-order -->
```text
?- consult('家族.pl').
true.
?- \+ 親(X, _), 人(X).
false.
```

5. if-then-else で選びます。`( Cond -> Then ; Else )` は、条件 `Cond` が成功すれば `Then` を、そうでなければ `Else` を実行します。全体を囲むかっこは省けません。

<!-- check: if-then-else -->
```text
?- X = 5, ( X > 0 -> S = 正 ; S = 負 ).
X = 5, S = 正.
?- X = -5, ( X > 0 -> S = 正 ; S = 負 ).
X = -5, S = 負.
```

6. 答えが多すぎる規則を見ます。`成績.pl` というファイルに次の行を書きます。点数が 80 以上なら `優`、60 以上なら `良`、それ以外は `可` です。最後の節の `_` は、そこでは点数を問わないことを表します。ファイルを読み込み、90 点の成績を、ピリオドが出るまで `;` を打ちながら尋ねます。90 は 60 以上でもあり、最後の節はどんな点数にも合うので、Mosa は成績を 3 つ見つけます。

<!-- file: grade-file 成績.pl -->
```prolog
成績(S, 優) :- S >= 80.
成績(S, 良) :- S >= 60.
成績(_, 可).
```

<!-- check: grade-many
consult('成績.pl').
成績(90, G).
;
;
-->
```text
?- consult('成績.pl').
true.
?- 成績(90, G).
G = 優;

G = 良;

G = 可.
```

7. カットで直します。`成績.pl` を下のように変えます。`!` はカットと読みます。カットは必ず成功しますが、残っている選択肢を捨てます。`成績/2` のある節でカットを通り過ぎると、Mosa はこのゴールについて、`成績/2` のほかの節を試しません。ですから、最初に成り立った条件が成績を決めます。成績は頭部ではなく、カットの後の `G = 優` で決めています。そのため、成績を与えて尋ねる問い合わせも正しく調べられ、`成績(90, 可)` は失敗します。

<!-- file: grade-cut-file 成績.pl -->
```prolog
成績(S, G) :- S >= 80, !, G = 優.
成績(S, G) :- S >= 60, !, G = 良.
成績(_, 可).
```

<!-- check: grade-cut -->
```text
?- consult('成績.pl').
true.
?- 成績(90, G).
G = 優.
?- 成績(70, G).
G = 良.
?- 成績(30, G).
G = 可.
?- 成績(90, 可).
false.
```

8. すべての答えを 1 つのリストに集めます。`findall(X, Goal, L)` は、ゴール `Goal` の答えをすべて見つけ、それぞれの答えでの `X` の値を並べたリストを `L` にします。答えの中の `X = X` は、`X` 自身には値がないことを表します。`findall/3` は `X` の値をリストに取り込み、`X` そのものには値を残しません。`Goal` に答えがないときは、リストは `[]` です。

<!-- check: findall -->
```text
?- consult('家族.pl').
true.
?- findall(X, 親(太郎, X), L).
X = X, L = [一郎,花子].
?- findall(X, 親(花子, X), L).
X = X, L = [].
```

9. `halt.` と打って終わります。

## 何が起きたか

この章では、探し方を操る方法を 4 つ使いました。

- `\+ Goal` は、ゴール `Goal` に答えがないときに成功し、答えがあるときに失敗します。値は入れません。Mosa は `Goal` の答えを探し、見つけたらそれを忘れます。これを失敗による否定と呼びます。ここでの「でない」は「Mosa が持っている事実と規則からは示せない」という意味だからです。`家族.pl` には花子の子がいないので、Mosa にとって花子には子がいません。
- `( Cond -> Then ; Else )` は、`Cond` の最初の答えだけを使い、ほかの答えを試しに戻ってくることはありません。
- `!` は 1 回だけ成功し、2 種類の選択肢を取り除きます。同じ述語の、今の節より下にある節と、その節でカットより前にあるゴールのほかの答えです。
- `findall/3` は、ゴールをすべての答えまで実行し、答えをリストにして返します。

手順 7 では、`成績(90, G)` はまず 1 つ目の節を試しました。`90 >= 80` が成り立ち、カットがほかの 2 つの節を取り除き、`G = 優` が答えになりました。もう選択肢がないので、Mosa は答えの後にピリオドを付けました。`成績(70, G)` は、1 つ目の節のカットに着く前に `70 >= 80` で失敗したので、Mosa は 2 つ目の節を試しました。カットがなければ、`良` には `S >= 60, S < 80` のように、条件どうしが重ならないように書く必要があります。

Mosa は、問い合わせの変数が最後まで値を持たないとき、その変数を `X = X` と書きます。ただし、第 5 章の `X = Y` や `X = 箱(Y)` のように、答えがその変数をほかの形で示すときは書きません。`X = X` は第 9 章にも出てきます。

## 練習問題

1. `最大.pl` というファイルに述語 `大きい方/3` を書いてください。`大きい方(X, Y, M)` は、`X` と `Y` の大きい方を `M` にします。if-then-else を使ってください。
2. `家族.pl` を使って、子がいない人が何人いるかを求めてください。`findall/3` と `length/2` を使ってください。

### 答え

1. `X >= Y` なら大きい方は `X`、そうでなければ `Y` です。

<!-- file: max-file 最大.pl -->
```prolog
大きい方(X, Y, M) :- ( X >= Y -> M = X ; M = Y ).
```

<!-- check: exercise-max -->
```text
?- consult('最大.pl').
true.
?- 大きい方(3, 7, M).
M = 7.
?- 大きい方(9, 2, M).
M = 9.
```

2. 3 人です。`findall/3` で集めてから、リストの長さを数えます。

<!-- check: exercise-count -->
```text
?- consult('家族.pl').
true.
?- findall(X, 子がいない(X), L), length(L, N).
X = X, L = [花子,桃子,三郎], N = 3.
```

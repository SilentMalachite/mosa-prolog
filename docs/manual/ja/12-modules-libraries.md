# 12. モジュールとライブラリ

この章では、Mosa に付いてくるライブラリを読み込んで `append/3`、`member/2`、`format/2` を使い、自分のモジュールを書きます。

## 手順

1. 第 4 章の `cd` の行でフォルダ `prolog` に移り、`mosa` を起動します。`append/3` で 2 つのリストをつなげてみます。`append/3` は、第 7 章で書いた `app/3` と同じ働きをする述語です。ところが Mosa は、第 3 章と同じ警告を出します。この述語はまだないからです。`append/3` はライブラリに入っています。ライブラリは、Mosa に付いてくる、Prolog で書いた述語のファイルです。ライブラリの述語は、`use_module/1` でライブラリを読み込んでから使えるようになります。ただし `use_module/1` はファイルの中でしか使えません。`?-` のプロンプトで打つと、同じような警告が出ます。

<!-- check: no-library -->
```text
?- append([赤, 緑], [青], X).
警告: ゴールは例外を送出しました: error(existence_error(procedure,append/3),context(append/3,_G1))
?- use_module(library(lists)).
警告: ゴールは例外を送出しました: error(existence_error(procedure,use_module/1),context(use_module/1,_G1))
```

2. フォルダ `prolog` に `ライブラリ.pl` というファイルを作り、次の 1 行を書きます。この行は、第 11 章と同じくディレクティブです。Mosa はファイルを読み込む途中で `use_module(library(lists))` を実行し、`lists` という名前のライブラリを読み込みます。`library(lists)` と書くと、Mosa は `mosa` の隣のフォルダ `lib` でライブラリを探します。第 2 章で Mosa のフォルダをそのままの形で置いておくように書いたのは、このためです。

<!-- file: libs-file ライブラリ.pl -->
```prolog
:- use_module(library(lists)).
```

3. ファイルを読み込み、もう一度 2 つのリストをつなげます。次に、`app/3` でしたのと同じようにリストを分けます。`false.` が出るまで `;` を打ちます。

<!-- check: append
consult('ライブラリ.pl').
append([赤, 緑], [青], X).
append(X, Y, [赤, 緑]).
;
;
;
-->
```text
?- consult('ライブラリ.pl').
true.
?- append([赤, 緑], [青], X).
X = [赤,緑,青].
?- append(X, Y, [赤, 緑]).
X = [], Y = [赤,緑];

X = [赤], Y = [緑];

X = [赤,緑], Y = [];

false.
```

4. 同じライブラリの `member/2` を使います。`member(X, L)` は、`X` がリスト `L` の要素のときに成り立ちます。`X` が変数なら、要素を 1 つずつ順に返します。`X` に値があれば、その値がリストにあるかどうかを確かめます。`X = 青` の後と、2 つ目の問い合わせの `true` の後では、第 4 章と同じように、Mosa はまだすべてを試していないので、ピリオドを付けずに待ちます。`;` を打つと、ほかに答えがないことが分かります。

<!-- check: member
consult('ライブラリ.pl').
member(X, [赤, 緑, 青]).
;
;
;
member(緑, [赤, 緑, 青]).
;
member(黒, [赤, 緑, 青]).
-->
```text
?- consult('ライブラリ.pl').
true.
?- member(X, [赤, 緑, 青]).
X = 赤;

X = 緑;

X = 青;

false.
?- member(緑, [赤, 緑, 青]).
true;

false.
?- member(黒, [赤, 緑, 青]).
false.
```

5. ライブラリ `format` の `format/2` で文を書き出します。フォルダ `prolog` に `値段.pl` というファイルを作り、次の行を書きます。第 6 章の値段の事実と、それを書き出す規則です。`format(Text, Args)` は原子 `Text` を書き出します。そのとき、`~w` はリスト `Args` の次の要素に置き換え、`write/1` と同じように書きます。`~n` は改行に置き換えます。`forall(Condition, Action)` は組み込みの述語で、`Condition` の答えごとに `Action` を 1 回ずつ実行し、`Action` がどれも成功したときに成功します。ですから `値段を書く` は、値段 1 つにつき 1 行を書き出します。

<!-- file: prices-file 値段.pl -->
```prolog
:- use_module(library(format)).

値段(りんご, 120).
値段(パン, 250).
値段(牛乳, 180).

値段を書く :- forall(値段(X, P), format('~wは ~w 円です~n', [X, P])).
```

6. ファイルを読み込み、`値段を書く` を実行します。

<!-- check: format -->
```text
?- consult('値段.pl').
true.
?- 値段を書く.
りんごは 120 円です
パンは 250 円です
牛乳は 180 円です
true.
```

7. 自分のモジュールを書きます。モジュールは、ほかのファイルの述語と分けておく述語のまとまりで、ふつうは 1 つのファイルです。モジュールは、公開した述語、つまり公開リストに書いた述語だけをほかのファイルに見せます。それ以外の述語は、モジュールの中にとどまります。フォルダ `prolog` に `家系.pl` というファイルを作り、次の行を書きます。1 行目はディレクティブ `module/2` です。1 つ目の引数でモジュールに、ファイルと同じ `家系` という名前を付けます。2 つ目の引数が公開リストで、公開する述語を `名前/アリティ` の形で並べます。`親/2` はリストにないので、モジュールの中にとどまります。

<!-- file: module-file 家系.pl -->
```prolog
:- module(家系, [祖父母/2]).

親(太郎, 一郎).
親(太郎, 花子).
親(一郎, 桃子).
親(一郎, 次郎).
親(次郎, 三郎).

祖父母(X, Z) :- 親(X, Y), 親(Y, Z).
```

8. ほかのファイルからモジュールを使います。フォルダ `prolog` に `報告.pl` というファイルを作り、次の行を書きます。`library(…)` を付けない `use_module(家系)` は、`報告.pl` のあるフォルダから、自分で書いたファイル `家系.pl` を読み込みます。ここでは `.pl` を省けます。このディレクティブは `祖父母/2` を取り込みます。取り込むとは、ほかのモジュールが公開した述語を、ここで使えるようにすることです。ですから規則 `孫を書く/1` は、`祖父母/2` を呼べます。

<!-- file: report-file 報告.pl -->
```prolog
:- use_module(家系).
:- use_module(library(format)).

孫を書く(X) :- forall(祖父母(X, Z), format('~wは~wの孫です~n', [Z, X])).
```

9. `報告.pl` を読み込み、太郎の孫を書き出します。`祖父母/2` はプロンプトでも使えます。`親/2` は使えません。公開していないので、`家系` の外からは、ないのと同じです。それでもモジュールの中の述語を呼ぶときは、ゴールの前にモジュールの名前とコロンを付けます。

<!-- check: module
consult('報告.pl').
孫を書く(太郎).
祖父母(X, 三郎).
;
親(太郎, X).
家系:親(太郎, X).
;
-->
```text
?- consult('報告.pl').
true.
?- 孫を書く(太郎).
桃子は太郎の孫です
次郎は太郎の孫です
true.
?- 祖父母(X, 三郎).
X = 一郎;

false.
?- 親(太郎, X).
警告: ゴールは例外を送出しました: error(existence_error(procedure,親/2),context(親/2,_G1))
?- 家系:親(太郎, X).
X = 一郎;

X = 花子.
```

10. `halt.` と打って終わります。

## 何が起きたか

述語はどれも、どこかのモジュールに属しています。`?-` のプロンプトと、`ライブラリ.pl` や `報告.pl` のような `module/2` のないファイルは、モジュール `user` を使います。ライブラリもモジュールです。`library(lists)` はモジュール `lists` で、`append/3` や `member/2` などを公開しています。`use_module/1` は、公開された述語を、そのディレクティブを書いたファイルのモジュールに取り込みます。`報告.pl` のモジュールは `user` なので、`祖父母/2` はプロンプトでも使えました。

`親/2` は `家系` の中にとどまりました。ほかのモジュールが自分の `親/2` を持っていても、2 つは混ざりません。たとえば第 4 章の `家族.pl` も読み込むと、プロンプトの `親/2` は `家族.pl` のもので、`家系:親(…)` はモジュールの中のものです。`Module:Goal` は、ゴール `Goal` をモジュール `Module` の中で実行します。

`use_module/1` に渡す名前は 2 種類あります。

- `library(Name)` はライブラリを表します。Mosa は、`mosa` の隣のフォルダ `lib` でファイル `Name.pl` を探します。
- `家系` のような名前だけのものは、自分で書いたファイルを表します。Mosa は、ディレクティブを書いたファイルのあるフォルダでそのファイルを探します。名前に `.pl` がなければ `.pl` を足すので、名前を全部書く必要のある `consult/1`（第 4 章）とは違います。`use_module('家系.pl')` と書いてもかまいません。その名前のファイルがないと、読み込みは止まります。Mosa は、読み込んでいたファイルの名前と、見つからなかった名前を出します。たとえば `use_module(家計)` と書き間違えると、`consult('報告.pl')` は `報告.pl: 家計: ファイルを開けません` と `false.` を出します。

`use_module/1` は、1 つのファイルを 1 回しか読み込みません。`家系.pl` を書き換えてから `報告.pl` をもう一度読み込んでも、Mosa は `家系.pl` を読み直さないので、変更は効きません。Mosa を終えて起動し直すか、`consult('家系.pl')` でモジュールのファイルそのものを読み込みます。`use_module/1` はプロンプトでは打てません。プロンプトでライブラリを使うときは、`ライブラリ.pl` のように、ディレクティブをファイルに書いて、そのファイルを読み込みます。

Mosa には次のライブラリが付いてきます。どれも `use_module(library(Name))` で読み込みます。

| ライブラリ | 主な述語 |
| --- | --- |
| `lists` | `append/3`、`member/2`、`reverse/2`、`last/2`、`nth1/3`、`sum_list/2`、`msort/2` |
| `apply` | `maplist/2` から `maplist/5`、`foldl/4` から `foldl/6`、`include/3`、`exclude/3` |
| `between` | `between/3`、`succ/2`、`plus/3` |
| `format` | `format/1`、`format/2`、`format/3` |
| `strings` | `atomic_list_concat/2`、`atomic_list_concat/3`、`split_atom/4`、`upcase_atom/2` |
| `japanese` | `ひらがな_カタカナ/2`、`全角_半角/2`、`読み幅/2` |

`length/2` も `lists` に入っていますが、組み込みでもあるので、第 7 章のようにライブラリなしで使えます。`atom_length/2` や `forall/2` のような組み込みの述語は、モジュール `system` にあり、どのモジュールからも使えます。

## 練習問題

1. `ライブラリ.pl` を読み込み、`library(lists)` の `reverse/2` で、リスト `[1, 2, 3]` を逆の順に並べてください。
2. `家系` から `親/2` も公開し、太郎の子が誰かをプロンプトで尋ねてください。

### 答え

1. `reverse(L, R)` は、`R` が `L` の要素を逆の順に並べたリストのときに成り立ちます。

<!-- check: exercise-reverse -->
```text
?- consult('ライブラリ.pl').
true.
?- reverse([1, 2, 3], L).
L = [3,2,1].
```

2. `家系.pl` の公開リストに `親/2` を加えます。

<!-- file: exercise-module-file 家系.pl -->
```prolog
:- module(家系, [親/2, 祖父母/2]).

親(太郎, 一郎).
親(太郎, 花子).
親(一郎, 桃子).
親(一郎, 次郎).
親(次郎, 三郎).

祖父母(X, Z) :- 親(X, Y), 親(Y, Z).
```

同じ対話の中では、`use_module/1` は書き換えたファイルを読み直しません。Mosa を終えて起動し直してから、`報告.pl` を読み込みます。

<!-- check: exercise-parent
consult('報告.pl').
親(太郎, X).
;
-->
```text
?- consult('報告.pl').
true.
?- 親(太郎, X).
X = 一郎;

X = 花子.
```

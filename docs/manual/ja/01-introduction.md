# 1. はじめに

この章では、Prolog と Mosa Prolog がどういうものかを知り、このマニュアルの例の読み方を覚えます。

## Prolog とは

多くのプログラミング言語では、コンピュータに実行させる手順を順に書きます。Prolog では、手順の代わりに、何が成り立つかを書きます。「太郎は一郎の親である」という事実や、「親の親は祖父母である」という規則を書いておき、そこに質問をします。Prolog は書かれた事実と規則を探して、質問に答えます。Prolog への質問を問い合わせと呼びます。

Prolog は、答えを探すこと、決まりに合っているかを調べること、文の組み立てを解析すること、パズルを解くことなどに使われます。問題を事実と規則の集まりとして考える練習にも向いています。

## Mosa Prolog とは

Mosa Prolog は、Prolog の国際規格 ISO/IEC 13211-1 に沿った Prolog 処理系です。次の 3 つのコマンドがあります。

- `mosa` は Prolog を動かします。問い合わせを打つと、答えを返します。第 2 章から第 12 章で使います。
- `mosac` は Prolog のプログラムを、`mosa` なしで動く実行ファイルにします。C++ のコンパイラが要ります。第 13 章で扱います。
- `mosatest` はテストを動かします。このマニュアルの例を確かめているのも、このコマンドです。

Mosa は文字を UTF-8 で読み書きします。そのため、名前を日本語で書けます。このマニュアルの日本語版の例も、日本語の名前で書いています。詳しくは第 11 章で扱います。

## 手順（例の読み方）

1. 次の例を見てください。問い合わせと、それへの Mosa の答えです。

<!-- check: first-look -->
```text
?- atom_length(こんにちは, N).
N = 5.
```

2. 1 行目は `?- ` で始まります。これは、Mosa が入力を待っているときに出す印（プロンプト）です。その後ろの `atom_length(こんにちは, N).` を自分で打ち、Enter を押します。この問い合わせは、「こんにちは」が何文字かを尋ねています。
3. その下の `N = 5.` は Mosa の出力です。「こんにちは」は 5 文字だ、という答えです。この行は打ちません。
4. `$ ` で始まる行も同じ読み方をします。こちらはシェルに打つ行で、`$ ` の後ろを打ちます。第 2 章はこの形の行から始まります。

## 何が起きたか

問い合わせとその答えを読みました。このマニュアルの例は、どれもリリースの前に Mosa 0.1.1 で実行してあります。問い合わせの下の出力は、そのとき Mosa が出したものです。`mosatest --manual` というコマンドが例を実行し直して、1 字でも違えば失敗にします。ですから、例をそのとおりに打てば、同じ出力が出るはずです。違う出力が出たら、打ち間違いか、[報告すべき不具合](https://github.com/SilentMalachite/mosa-prolog/issues)のどちらかです。よく見比べてください。

## 練習問題

1. 上の例で、自分で打つのはどの行ですか。Mosa が出すのはどの行ですか。

### 答え

1. 自分で打つのは `atom_length(こんにちは, N).` です（`?- ` の後ろ）。Mosa が出すのは `N = 5.` です。

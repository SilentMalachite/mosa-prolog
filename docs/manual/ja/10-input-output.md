# 10. 入出力

この章では、`write/1` と `nl/0` で項を書き出し、自分で打った項を `read/1` で読み込み、ファイルに書いてから読み戻します。

## 手順

1. 第 4 章の `cd` の行でフォルダ `prolog` に移り、`mosa` を起動します。言葉を 1 つ書き出します。`write/1` は項を書き出し、`nl/0` は改行します。その後に、Mosa がいつものように答え `true.` を出します。

<!-- check: write -->
```text
?- write(こんにちは), nl.
こんにちは
true.
```

2. 引用符で囲んだ原子と、変数の値を書き出します。`write/1` は、原子を引用符なしで書き出します。2 つ目の問い合わせでは、`42` が `write/1` の書き出したもので、`X = 42.` が Mosa の答えです。

<!-- check: write-more -->
```text
?- write('こんにちは 世界'), nl.
こんにちは 世界
true.
?- X is 6 * 7, write(X), nl.
42
X = 42.
```

3. `nl` を省いてみます。`こんにちは` の後で改行しないので、Mosa の答えが同じ行に続きます。

<!-- check: no-nl -->
```text
?- write(こんにちは).
こんにちはtrue.
```

4. 自分で打った項を読み込みます。`read(X)` は、項が打たれるのを待ち、`X` をその項と単一化します。待っている間、Mosa はプロンプトを出しません。問い合わせと同じように項の最後に半角のピリオドを付け、Enter を押します。ピリオドの前に Enter を押すと、問い合わせのときと同じように、Mosa は待ち続けます。そのときは、下の 2 つ目の問い合わせのように、ピリオドを打ってもう一度 Enter を押します。日本語入力をオンにしたまま全角の「。」を打つと、項は終わらず、Mosa は何も出さずに待ち続けます。そのときは半角の `.` を打って Enter を押します。`syntax_error` を含む警告が出るので、問い合わせを打ち直してください。

<!-- check: read
read(X).
こんにちは.
read(X).
こんにちは
.
-->
```text
?- read(X).
こんにちは.
X = こんにちは.
?- read(X).
こんにちは
.
X = こんにちは.
```

5. 数を読み込んで計算します。Mosa が待っているところで `21.` と打ちます。

<!-- check: read-number
read(X), Y is X * 2.
21.
-->
```text
?- read(X), Y is X * 2.
21.
X = 21, Y = 42.
```

6. 質問をするプログラムを書きます。フォルダ `prolog` に `あいさつ.pl` というファイルを作り、次の規則を書きます。`あいさつ` は質問を書き出し、名前を読み込んで、その名前であいさつを書き出します。

<!-- file: greet-file あいさつ.pl -->
```prolog
あいさつ :- write('お名前は？'), nl, read(X), write('こんにちは、'), write(X), write('さん'), nl.
```

7. ファイルを読み込み、`あいさつ` を実行します。名前を聞かれたら `太郎.` と打って Enter を押します。次に、もう一度実行して、ローマ字で `Taro.` と大文字から打ちます。アルファベットの大文字で始まる名前は変数なので（第 5 章）、`read/1` は `X` を新しい変数にし、`write/1` は Mosa が付けた名前 `_G1` を書き出します。大文字で始まる名前を読ませるときは、単一引用符で囲みます。

<!-- check: greet
consult('あいさつ.pl').
あいさつ.
太郎.
あいさつ.
Taro.
あいさつ.
'Taro'.
-->
```text
?- consult('あいさつ.pl').
true.
?- あいさつ.
お名前は？
太郎.
こんにちは、太郎さん
true.
?- あいさつ.
お名前は？
Taro.
こんにちは、_G1さん
true.
?- あいさつ.
お名前は？
'Taro'.
こんにちは、Taroさん
true.
```

8. ファイルに書いてから読み戻します。Mosa は、ストリームを通してファイルを読み書きします。ストリームは、文字を読む元や書く先とのつながりで、読む元や書く先はファイルのことも、端末のこともあります。`open(File, Mode, S)` は、ファイル `File` を開き、そのファイルのストリームを `S` にします。`Mode` は、ファイルに書くときは `write`、読むときは `read` です。`write/2` と `nl/1` は `write/1` と `nl/0` と、`read/2` は `read/1` と同じ働きをしますが、1 つ目の引数にストリームを取り、端末の代わりにそのストリームを使います。使い終わったら、`close(S)` でストリームを閉じます。フォルダ `prolog` に `メモ.pl` というファイルを作り、次の 2 つの規則を書きます。`書く` は、ファイル `メモ.txt` を書き込み用に開き、項 `買う(牛乳)` とピリオドを書き込み、改行して、ファイルを閉じます。`読む(T1, T2)` は、同じファイルを読み込み用に開き、項を 2 つ読み込んで、ファイルを閉じます。

<!-- file: notes-file メモ.pl -->
```prolog
書く :- open('メモ.txt', write, S), write(S, 買う(牛乳)), write(S, '.'), nl(S), close(S).
読む(T1, T2) :- open('メモ.txt', read, S), read(S, T1), read(S, T2), close(S).
```

9. ファイルを読み込み、メモを書いてから読み戻します。1 つ目の項は `買う(牛乳)` です。2 つ目の項はないので、`read/2` は原子 `end_of_file` を返します。

<!-- check: file -->
```text
?- consult('メモ.pl').
true.
?- 書く.
true.
?- 読む(T1, T2).
T1 = 買う(牛乳), T2 = end_of_file.
```

ファイル `メモ.txt` は、Mosa を起動したフォルダ `prolog` にできています。テキストエディタで開くと、`買う(牛乳).` という 1 行が見えます。

10. ないファイルを読もうとしてみます。`open/3` は `existence_error` を投げます。`source_sink` は、ファイルのような、読み書きする先を表します。

<!-- check: missing -->
```text
?- open('ない.txt', read, S).
警告: ゴールは例外を送出しました: error(existence_error(source_sink,'ない.txt'),context(open/3,_G1))
```

11. `halt.` と打って終わります。

## 何が起きたか

端末もストリームの一つです。`write/1`、`nl/0`、`read/1` は端末を使い、端末に書き出し、端末で打たれたものを読みます。`write/2`、`nl/1`、`read/2` は、引数で渡されたストリームを使います。

`Mode` には `append` も使えます。`append` は、ファイルの終わりに書き足します。`write` は、ファイルがすでにあれば、先に中身を空にします。開いたストリームは必ず閉じてください。閉じるまでは、書いたものの一部がまだファイルに入っていないことがあります。ストリームは `メモ.pl` の規則の中だけで使っています。`S` はそれぞれの規則の変数なので、答えには出てきません。ファイル名は原子なので、ピリオドを含むときは、`consult('家族.pl')` と同じように単一引用符で囲みます。

`read/1` と `read/2` は、項を 1 つ、その項を終えるピリオドまで読みます。もう読むものがないときは、原子 `end_of_file` を返します。

`write/1` と `write/2` は原子を引用符なしで書くので、書いたものを読み戻せないことがあります。`writeq/1` と `writeq/2` は引用符も書きます。違いを確かめるため、次のファイルを `引用.pl` という名前で保存します。`そのまま書く` は原子 `'こんにちは 世界'` を `write/2` で、`引用符も書く` は `writeq/2` で書きます。`読み戻す(T)` は、`catch/3`（第 9 章）の中で項を 1 つ読みます。かっこの中の 2 つのゴールが、その `Recovery` です。`read/2` がエラーを投げると、`読み戻す/1` はストリームを閉じてから同じ例外を投げ直すので、ストリームが開いたまま残ることはありません。

<!-- file: quoted-file 引用.pl -->
```prolog
そのまま書く :- open('引用.txt', write, S), write(S, 'こんにちは 世界'), write(S, '.'), nl(S), close(S).
引用符も書く :- open('引用.txt', write, S), writeq(S, 'こんにちは 世界'), write(S, '.'), nl(S), close(S).
読み戻す(T) :- open('引用.txt', read, S), catch(read(S, T), E, (close(S), throw(E))), close(S).
```

`そのまま書く` の後、ファイルには `こんにちは 世界.` と書かれています。`read/2` はこれを読めません。原子 `こんにちは` の後に、空白だけをはさんで原子 `世界` を続けることはできないからです。そのため `読み戻す/1` は構文エラーを投げます。下の問い合わせはそれを捕まえて、`Formal` の `syntax_error(unexpected_token)` を示します。読み戻す項はないので、`読み戻す/1` には `_` を渡しています。`引用符も書く` の後は、ファイルに `'こんにちは 世界'.` と書かれていて、原子がそのまま戻ってきます。

<!-- check: writeq -->
```text
?- consult('引用.pl').
true.
?- そのまま書く.
true.
?- catch(読み戻す(_), error(E, _), true).
E = syntax_error(unexpected_token).
?- 引用符も書く.
true.
?- 読み戻す(T).
T = 'こんにちは 世界'.
```

## 練習問題

1. `read/1` で数を読み込み、その 2 乗を書き出してください。Mosa が待っているところで `7.` と打ちます。
2. `全部書く.pl` というファイルに、リストの要素を 1 行に 1 つずつ書き出す述語 `全部書く/1` を書いてください。第 7 章と同じように再帰を使います。

### 答え

1. `49` は `write/1` が書き出したもので、最後の行が Mosa の答えです。

<!-- check: exercise-square
read(X), Y is X * X, write(Y), nl.
7.
-->
```text
?- read(X), Y is X * X, write(Y), nl.
7.
49
X = 7, Y = 49.
```

2. `[]` なら、書き出すものはありません。頭部が `X` で尾部が `T` のリストなら、`X` を書き出して改行し、それから `T` の要素を書き出します。

<!-- file: print-file 全部書く.pl -->
```prolog
全部書く([]).
全部書く([X|T]) :- write(X), nl, 全部書く(T).
```

<!-- check: exercise-print -->
```text
?- consult('全部書く.pl').
true.
?- 全部書く([赤, 緑, 青]).
赤
緑
青
true.
```

# 7. リストと再帰

この章では、リストを書き、リストを頭部と尾部に分け、自分自身を使ってリストをたどる述語を書きます。

## 手順

1. 第 4 章の `cd` の行でフォルダ `prolog` に移り、`mosa` を起動します。リストを書きます。リストは、項を角かっこ `[` `]` の中にコンマで区切って並べたものです。`[]` は要素が 1 つもない空リストです。Mosa は複合項と同じように、コンマの後に空白を入れずにリストを書きます。

<!-- check: list -->
```text
?- X = [赤, 緑, 青].
X = [赤,緑,青].
?- X = [].
X = [].
```

2. リストを分けます。`[H|T]` の縦棒 `|` は、最初の要素と、残りの要素のリストを区切ります。最初の要素を頭部（ヘッド）、残りのリストを尾部（テイル）と呼びます。尾部はいつもリストです。要素が 1 つのリストの尾部は `[]` です。空リストには頭部がないので、`[H|T]` とは単一化できません。

<!-- check: head-tail -->
```text
?- [H|T] = [赤, 緑, 青].
H = 赤, T = [緑,青].
?- [H|T] = [赤].
H = 赤, T = [].
?- [H|T] = [].
false.
```

3. 先頭から 2 つ以上の要素を取り出します。縦棒の前には、コンマで区切って要素をいくつでも書けます。

<!-- check: two-heads -->
```text
?- [A, B|T] = [1, 2, 3, 4].
A = 1, B = 2, T = [3,4].
```

4. リストの前に要素を付けます。`[赤|[緑, 青]]` は、頭部が `赤` で尾部が `[緑, 青]` のリストです。これは `[赤, 緑, 青]` と同じリストです。

<!-- check: cons -->
```text
?- L = [赤|[緑, 青]].
L = [赤,緑,青].
```

5. 組み込みの述語 `length/2` で要素の数を数えます。

<!-- check: length -->
```text
?- length([赤, 緑, 青], N).
N = 3.
?- length([], N).
N = 0.
```

6. 要素を数える述語を自分で書きます。フォルダ `prolog` に `リスト.pl` というファイルを作り、次の 2 つの節を書きます。1 つ目の節は「空リストの要素は 0 個である」と言っています。2 つ目の節は「尾部 `T` の要素が `N0` 個で、`N` が `N0 + 1` なら、何かの頭部と尾部 `T` からなるリストの要素は `N` 個である」と言っています。2 つ目の節は、尾部を数えるのに `数える/2` 自身を使っています。このように自分自身を使う述語を再帰的な述語と呼び、この問題の解き方を再帰と呼びます。

<!-- file: count-file リスト.pl -->
```prolog
数える([], 0).
数える([_|T], N) :- 数える(T, N0), N is N0 + 1.
```

7. ファイルを読み込み、いくつかのリストの要素を数えます。

<!-- check: count -->
```text
?- consult('リスト.pl').
true.
?- 数える([赤, 緑, 青], N).
N = 3.
?- 数える([], N).
N = 0.
```

8. 2 つのリストをつなぎます。`リスト.pl` に、下の述語 `つなぐ/3` を書き足します。`つなぐ(A, B, C)` は、リスト `A` の後にリスト `B` を続けたものが `C` のときに成り立ちます。1 つ目の節は「空リストの後に `L` を続けると `L` である」と言っています。2 つ目の節は「`T` の後に `L` を続けたものが `R` なら、頭部が `H` で尾部が `T` のリストの後に `L` を続けると、頭部が `H` で尾部が `R` のリストになる」と言っています。

<!-- file: app-file リスト.pl -->
```prolog
数える([], 0).
数える([_|T], N) :- 数える(T, N0), N is N0 + 1.

つなぐ([], L, L).
つなぐ([H|T], L, [H|R]) :- つなぐ(T, L, R).
```

9. ファイルをもう一度読み込み、`[あ, い]` と `[う, え]` をつなぎます。

<!-- check: app -->
```text
?- consult('リスト.pl').
true.
?- つなぐ([あ, い], [う, え], X).
X = [あ,い,う,え].
```

10. `つなぐ/3` を逆向きに使います。つないだ後のリストだけを与えて、どの 2 つのリストをつなぐとそれになるかを尋ねます。`false.` が出るまで `;` を打ちます。`[あ, い]` の分け方は 3 通りあります。

<!-- check: app-split
consult('リスト.pl').
つなぐ(X, Y, [あ, い]).
;
;
;
-->
```text
?- consult('リスト.pl').
true.
?- つなぐ(X, Y, [あ, い]).
X = [], Y = [あ,い];

X = [あ], Y = [い];

X = [あ,い], Y = [];

false.
```

11. `halt.` と打って終わります。

## 何が起きたか

リストは、空リスト `[]` か、頭部と尾部の組 `[H|T]` のどちらかです。尾部もまたリストです。`[赤, 緑, 青]` は `[赤|[緑|[青|[]]]]` を短く書いたものです。ですから、`[]` の節と `[H|T]` の節が 1 つずつあれば、どんなリストも扱えます。

手順 7 で、Mosa が `数える([赤, 緑, 青], N)` の答えを見つけた順は次のとおりです。

1. `[赤, 緑, 青]` は `[]` と単一化できないので、1 つ目の節は合いません。2 つ目の節は `T = [緑, 青]` で合います。その最初のゴールは `数える([緑, 青], N0)` です。
2. このゴールは、同じように `数える([青], …)` を、それは `数える([], …)` を尋ねます。これらのゴールは、どれも節を新しく使うもので、問い合わせと同じように、それぞれ自分の変数を持ちます。
3. `数える([], …)` は 1 つ目の節に合い、0 になります。すると、待っていたゴールが順に `is/2` を済ませます。`[青]` の要素は 0 + 1 = 1 個、`[緑, 青]` は 1 + 1 = 2 個、`[赤, 緑, 青]` は 2 + 1 = 3 個です。

このように、再帰的な述語には 2 種類の節が要ります。すぐに答えられる場合の節（ここでは `[]`）と、大きな場合を小さな場合に帰着させる節（ここでは、リストからその尾部へ）です。1 歩ごとにリストが短くなるので、再帰は必ず `[]` にたどり着きます。

`つなぐ/3` も同じように動きます。Mosa は単一化をしているだけなので、逆向きにも使えます。手順 10 では、つなぐと `[あ, い]` になる `X` と `Y` を、Mosa がすべて探しました。

ここでは、間違いやすいところが 2 つあります。次のファイルを `間違い.pl` という名前で保存すると、それぞれどうなるかを確かめられます。`数える2/2` は `is/2` の代わりに `=` を使っているので、計算せずに `0+1+1+1` という項を作ります（第 6 章）。`数える3/2` には `[]` の節がないので、再帰が `[]` にたどり着いたときに合う節がなく、問い合わせ全体が失敗します。

<!-- file: wrong-file 間違い.pl -->
```prolog
数える2([], 0).
数える2([_|T], N) :- 数える2(T, N0), N = N0 + 1.

数える3([_|T], N) :- 数える3(T, N0), N is N0 + 1.
```

<!-- check: wrong -->
```text
?- consult('間違い.pl').
true.
?- 数える2([赤, 緑, 青], N).
N = 0+1+1+1.
?- 数える3([赤, 緑, 青], N).
false.
```

## 練習問題

1. `リスト.pl` に述語 `合計/2` を書き足し、`S` がリスト `L` の数の合計のときに `合計(L, S)` が成り立つようにしてください。`[1, 2, 3]` で試してください。
2. `つなぐ/3` を使って、`[あ, い, う]` の最後の要素を求めてください。最後の要素を `X` とすると、リストの終わりには `[X]` があることを使います。

### 答え

1. `[]` の合計は 0 です。頭部が `X` で尾部が `T` のリストの合計は、`X` に `T` の合計を足したものです。

<!-- file: sum-file リスト.pl -->
```prolog
数える([], 0).
数える([_|T], N) :- 数える(T, N0), N is N0 + 1.

つなぐ([], L, L).
つなぐ([H|T], L, [H|R]) :- つなぐ(T, L, R).

合計([], 0).
合計([X|T], S) :- 合計(T, S0), S is S0 + X.
```

<!-- check: exercise-sum -->
```text
?- consult('リスト.pl').
true.
?- 合計([1, 2, 3], S).
S = 6.
```

2. 何かのリストに `[X]` をつなぐと `[あ, い, う]` になる、と尋ねます。`_` は前の部分 `[あ, い]` を表しますが、その値は要りません。`;` を打つと、Mosa はほかの分け方を見つけられません。

<!-- check: exercise-last
consult('リスト.pl').
つなぐ(_, [X], [あ, い, う]).
;
-->
```text
?- consult('リスト.pl').
true.
?- つなぐ(_, [X], [あ, い, う]).
X = う;

false.
```

# Mosa Prolog マニュアル

Mosa Prolog 0.1.0 のマニュアルです。Prolog を使ったことのない人に向けて書いています。Mosa の入手から始めて、プログラムを書くところ、実行ファイルを作るところまで、少しずつ進みます。

## 読み方

- 章は順に読んでください。どの章も、それより前の章で出てきたことだけを使います。
- 各章の最初の 1 文に、その章で何をするかを書いています。その後に、自分で打つ番号付きの手順、手順を説明する「何が起きたか」、答え付きの練習問題が 1 つか 2 つ続きます。
- `?- ` で始まる行は問い合わせです。`?- ` の後ろを自分で打ちます。その下の行は Mosa の出力です。`$ ` で始まる行は、シェル（macOS と Linux ではターミナル、Windows では PowerShell）に打つコマンドです。`$ ` の後ろを打ちます。PowerShell だけの行は、プロンプトを付けずに載せています。この行は全部をそのまま打ちます。`$bin = …` のように行頭に `$` があれば、それもコマンドの一部なので打ちます。
- 例はすべて、`mosatest --manual` が Mosa 0.1.0 で実行して確かめています。出力が 1 字でも違えば検査は失敗します。ですから、ここに書いてある出力は Mosa が実際に出すものです。実行しないのは、インストールの手順のように、使う機械によって変わるものだけです。

## 動作環境

- macOS 14 以降（Apple Silicon）
- Linux（x86_64）。glibc が Ubuntu 24.04 と同じか、それより新しいもの
- Windows 10 22H2 以降と Windows 11（x64）。Smart App Control が無効のもの

パッケージには署名がありません。macOS と Windows で警告が出たときの進め方は、[第 2 章](02-install.md) に書いています。

# 3. 最初の問い合わせ

この章では、`?-` のプロンプトで Mosa に問い合わせをして、答えの読み方を覚えます。`true.` と `false.`、変数の値、`;` で次の答えを出すことを扱います。

## 手順

1. 第 2 章と同じように、シェルで `mosa` と打って Mosa を起動します。Mosa は `?- ` を出して待ちます。
2. 2 つの言葉が同じかどうかを尋ねます。`=` は、左右を同じにできるかを Mosa に尋ねます。`こんにちは` のような、漢字やかな、またはアルファベットの小文字で始まる名前は原子（アトム）です。原子は、それ自身を表す名前です。

<!-- check: same -->
```text
?- こんにちは = こんにちは.
true.
?- こんにちは = 世界.
false.
```

3. 変数を使って尋ねます。`X` のように、アルファベットの大文字で始まる名前は変数です。変数は、Mosa が探す値の入れ物です。Mosa は、問い合わせを正しくする値を答えます。

<!-- check: variable -->
```text
?- X = こんにちは.
X = こんにちは.
```

4. 2 つのゴール（問い合わせの中の、1 つ 1 つの問い）をコンマでつなぎます。コンマは「かつ」の意味で、両方が正しくなければなりません。2 つ目の問い合わせでは、`X` が `こんにちは` と `世界` の両方になることはできないので、答えは `false.` です。

<!-- check: and -->
```text
?- X = こんにちは, Y = 世界.
X = こんにちは, Y = 世界.
?- X = こんにちは, X = 世界.
false.
```

5. ゴールをセミコロンでつなぎます。セミコロンは「または」の意味です。Mosa は答えを 1 つ見つけると、末尾にピリオドを付けずに待ちます。`;` と打って Enter を押すと、次の答えを出します。最後の答えの後には、Mosa がピリオドを付けます。

<!-- check: or-all
X = 赤 ; X = 緑 ; X = 青.
;
;
-->
```text
?- X = 赤 ; X = 緑 ; X = 青.
X = 赤;

X = 緑;

X = 青.
```

6. 同じ問い合わせをもう一度打ちます。今度は、2 つ目の答えの後で Enter だけを押します。Mosa はピリオドを出して、探すのをやめます。

<!-- check: or-stop
X = 赤 ; X = 緑 ; X = 青.
;

-->
```text
?- X = 赤 ; X = 緑 ; X = 青.
X = 赤;

X = 緑
.
```

7. 組み込みの述語を使います。述語は、Mosa が答えられる、名前の付いた問いです。`atom_length/2` は Mosa に初めから入っている述語で、`/2` は引数を 2 つ取ることを表します。`atom_length(こんにちは, N)` は、`N` が「こんにちは」の字数のときに正しくなります。両方の引数を与えて、`true.` か `false.` かを尋ねることもできます。

<!-- check: builtin -->
```text
?- atom_length(こんにちは, N).
N = 5.
?- atom_length(こんにちは, 5).
true.
?- atom_length(こんにちは, 3).
false.
```

8. 問い合わせを 2 行に分けて打ちます。Mosa はピリオドを読むまで答えないので、問い合わせの途中で Enter を押して、次の行に続きを打てます。

<!-- check: two-lines
atom_length(こんにちは,
N).
-->
```text
?- atom_length(こんにちは,
N).
N = 5.
```

9. ない述語について尋ねます。Mosa は警告を出します。読み方は第 9 章で説明します。ここでは、引数のない述語 `こんにちは`（`こんにちは/0`）はない、と言っていることだけ分かれば十分です。

<!-- check: unknown -->
```text
?- こんにちは.
警告: ゴールは例外を送出しました: error(existence_error(procedure,こんにちは/0),context(こんにちは/0,_G1))
```

10. `halt.` と打って終わります。

## 何が起きたか

`?- ` の後に打った行は、どれも問い合わせです。問い合わせの中で `,` や `;` でつないだ 1 つ 1 つがゴールです。Mosa は問い合わせを正しくしようとします。

- `true.` は、正しいこと、そして知らせる値がないことを表します。
- `false.` は、正しくする方法が見つからなかったことを表します。
- `X = こんにちは.` は、変数 `X` の値が `こんにちは` のときに正しいことを表します。変数は、問い合わせの終わりまで同じ値を持ち続けます。`X = こんにちは, X = 世界` が正しくならないのはそのためです。

問い合わせを正しくする方法が 2 つ以上あると、Mosa は最初の答えを出し、ピリオドを付けずに待ちます。`;` を打つと次の答えを出し、その前に空の行を 1 行出します。Enter だけを押すと探すのをやめ、ピリオドだけの行を出します。`X = 青.` のように答えのすぐ後にピリオドが付くのは、もう答えがないことを Mosa が知っているときです。

名前の書き方には意味があります。`こんにちは` と `世界` は漢字やかなで始まるので原子です。`X`、`Y`、`N` は大文字で始まるので変数です。日本語には大文字と小文字の区別がないので、日本語で始まる名前は原子になります。日本語の名前の変数の書き方は第 11 章で扱います。

## 練習問題

1. `ぷろろぐ` は何文字ですか。Mosa に尋ねてください。
2. `X = 猫 ; X = 犬` の答えをすべて出してください。

### 答え

1. 4 文字です。

<!-- check: exercise-length -->
```text
?- atom_length(ぷろろぐ, N).
N = 4.
```

2. `;` を 1 回打ちます。もう答えがないので、`犬` の後に Mosa はピリオドを付けます。

<!-- check: exercise-or
X = 猫 ; X = 犬.
;
-->
```text
?- X = 猫 ; X = 犬.
X = 猫;

X = 犬.
```

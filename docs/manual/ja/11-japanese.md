# 11. 日本語で書く

この章では、日本語の名前の原子と変数を書き、原子の文字を数え、全角の記号で Prolog を書き、Mosa のメッセージの言語を選びます。

第 4 章から日本語の名前を使ってきましたが、この章では、その決まりと、日本語を使うときに気を付けることをまとめて確かめます。

## 手順

1. 第 4 章の `cd` の行でフォルダ `prolog` に移り、`mosa` を起動します。日本語で原子を書きます。漢字、ひらがな、カタカナには大文字と小文字の区別がありません。そのため Mosa は、これらで始まる言葉を、小文字で始まる言葉と同じように原子として読みます。引用符は要りません。

<!-- check: atoms -->
```text
?- X = 東京.
X = 東京.
?- X = [りんご, バナナ, 寿司].
X = [りんご,バナナ,寿司].
```

2. 日本語の名前の変数を作ります。`名前` は原子なので、`名前 = 太郎` は 2 つの違う原子が同じかどうかを尋ねることになり、答えは `false.` です。日本語の名前の変数は、`_名前` のように下線 `_` で始めます。この決まりは、`help.` と打てばいつでも見られます。`help` は述語ではなく `?-` のプロンプトの命令で、Mosa は 1 行の説明だけを出し、`true.` は出しません。

<!-- check: variables -->
```text
?- 名前 = 太郎.
false.
?- _名前 = 太郎.
_名前 = 太郎.
?- help.
日本語の名前の変数は _太郎 のように下線で始める。下線の無い 太郎 は原子である。
```

3. 原子の文字を数えます。Mosa では、Unicode の符号位置 1 つが 1 文字です。Unicode は世界中の文字の一つ一つに番号を付けた規格で、その番号を符号位置（コードポイント）と呼びます。ですから `東京` は 2 文字で、`𠮷野家` は 3 文字です。「吉」の異体字の `𠮷` を 2 文字と数えるプログラムもありますが、Mosa は 1 文字と数えます。`atom_chars/2` は、原子の文字のリストを返します。日本語入力で `𠮷` を出せないときは、このページから写してください。

<!-- check: count -->
```text
?- atom_length(東京, N).
N = 2.
?- atom_length('𠮷野家', N).
N = 3.
?- atom_chars(日本語, L).
L = [日,本,語].
```

4. 同じに見えて違う原子を見てみます。`atom_codes/2` は原子の符号位置のリストを返し、逆に符号位置のリストから原子を作ることもできます。`が` の符号位置は 12364 です。同じ見た目は、`か`（12363）の後に結合用の濁点（12441）を続けた 2 つの符号位置でも作れます。結合用の濁点は、画面では前の文字に重ねて描かれます。2 つ目の問い合わせはその原子を作ります。見た目は `が` ですが 2 文字で、3 つ目の問い合わせのとおり、自分で打った `が` とは別の原子です。

<!-- check: normalization -->
```text
?- atom_codes(が, L).
L = [12364].
?- atom_codes(A, [12363, 12441]), atom_length(A, N).
A = が, N = 2.
?- atom_codes(A, [12363, 12441]), A = が.
false.
```

5. 全角の記号で問い合わせを打ちます。日本語入力をオンにしたまま打つと、`(` の代わりに `（`、`,` の代わりに `、`、`.` の代わりに `。` のような全角の記号が入ります。Mosa には、フラグと呼ぶ設定がいくつかあります。フラグには名前と値があり、`current_prolog_flag(Name, Value)` は、名前が `Name` のフラグの値を `Value` に返します。フラグ `japanese_punctuation` は、Mosa を起動したときには `false` です。そのため Mosa は `（` をかっこと読まず、読むのをやめた列 6 を出します。

<!-- check: punct-off -->
```text
?- current_prolog_flag(japanese_punctuation, F).
F = false.
?- X = 親（子）。
構文エラー: 行 1 列 6: 予期しないトークン （
```

6. フラグの値を変える `set_prolog_flag/2` で、全角記号モードをオンにします。すると Mosa は、全角の記号を半角の記号として読みます。答えはいつも半角で書きます。かぎかっこ `「` `」` は、単一引用符として働きます。次の手順のために、最後にモードをオフに戻します。

<!-- check: punct-on -->
```text
?- set_prolog_flag(japanese_punctuation, true).
true.
?- X = 親（子）。
X = 親(子).
?- X = 親（太郎、一郎）。
X = 親(太郎,一郎).
?- X = 「東 京」。
X = '東 京'.
?- set_prolog_flag(japanese_punctuation, false).
true.
```

7. 全角の記号でファイルを書きます。フォルダ `prolog` に `首都.pl` というファイルを作り、次の行を書きます。1 行目はディレクティブです。ディレクティブは、`:-` で始まり、その前に何もない節です。Mosa はディレクティブをしまっておかず、ファイルを読み込む途中で `:-` の後のゴールを実行します。このディレクティブは、ファイルの残りの部分で全角記号モードをオンにします。Mosa がこの行を読むときにはまだモードがオフなので、この行だけは半角で書きます。事実はそれぞれ、ある国の首都がどの都市かを表します。`ワシントン D.C.` は空白とピリオドを含むので、かぎかっこで囲みます。

<!-- file: capital-file 首都.pl -->
```prolog
:- set_prolog_flag(japanese_punctuation, true).

首都（日本、東京）。
首都（フランス、パリ）。
首都（アメリカ、「ワシントン D.C.」）。
```

8. ファイルを読み込み、すべての首都を半角の記号で尋ねます。ピリオドが出るまで `;` を打ちます。それからフラグを調べます。ディレクティブがモードをオンにしたのはファイルの終わりまでなので、プロンプトではまたオフになっています。

<!-- check: punct-file
consult('首都.pl').
首都(X, Y).
;
;
current_prolog_flag(japanese_punctuation, F).
-->
```text
?- consult('首都.pl').
true.
?- 首都(X, Y).
X = 日本, Y = 東京;

X = フランス, Y = パリ;

X = アメリカ, Y = 'ワシントン D.C.'.
?- current_prolog_flag(japanese_punctuation, F).
F = false.
```

9. Mosa のメッセージの言語を変えます。フラグ `message_language` の値は `ja`（日本語）か `en`（英語）です。値を `en` にして、第 6 章の構文エラーと第 3 章の警告を出してみます。エラーのまわりの文は英語になりますが、エラーの項 `error(existence_error(…), …)` そのものは変わりません。最後に `ja` に戻します。

<!-- check: language -->
```text
?- current_prolog_flag(message_language, L).
L = ja.
?- set_prolog_flag(message_language, en).
true.
?- 3 <= 5.
Syntax error: line 1 column 3: unexpected token <=
?- こんにちは.
Warning: goal raised exception: error(existence_error(procedure,こんにちは/0),context(こんにちは/0,_G1))
?- set_prolog_flag(message_language, ja).
true.
```

10. `halt.` と打って終わります。次に、最初から英語のメッセージで Mosa を起動してみます。macOS と Linux では、`mosa` の前に `LANG=en_US.UTF-8` を付けます。こう書くと、`LANG` はこのコマンドにだけ設定されます。

<!-- skip: lang-unix -->
```console
$ LANG=en_US.UTF-8 mosa
```

Windows の PowerShell では、先にこのウィンドウの `LANG` を設定してから、`mosa` を起動します。

<!-- skip: lang-windows -->
```powershell
$env:LANG = "en_US.UTF-8"
mosa
```

`こんにちは.` と打つと、手順 9 と同じように、警告が英語で出ます。`halt.` と打って終わります。PowerShell で設定した `LANG` は、ウィンドウを閉じるまで残ります。

## 何が起きたか

Mosa は、ファイルも、打たれた行も、すべて UTF-8 として読みます。UTF-8 は、Unicode の文字を保存するときによく使う形式です。Mosa は、読んだ文字を Unicode の分類に従って次のように分けます。

- 漢字、ひらがな、カタカナのように大文字と小文字の区別のない文字は、小文字と同じに扱います。この文字で始まる言葉は原子です。
- 変数を始めるのは、大文字（`A` から `Z` と、`Ä` や `Σ` のようなほかのアルファベットの大文字）と下線 `_` だけです。ですから日本語の名前の変数は、`_` から始めるか、`X人` のように大文字から始めます。
- 全角の空白は、半角の空白と同じに扱います。
- 数字は半角の `0` から `9` だけです。全角の `１` は使えない文字で、全角記号モードでも変わりません。全角の数字を含む問い合わせには、構文エラーが出ます。

Mosa の組み込みの述語は、どれも文字を Unicode の符号位置で数えます。ですから `atom_length/2`、`atom_chars/2`、`atom_codes/2` の数え方はそろっています。

Mosa は 2 つの原子を、UTF-8 のバイトの並びで比べます。Unicode の正規化（NFC や NFD）はしません。正規化は、`が` の 2 つの形のような組を 1 つの形にそろえる処理で、これをするプログラムもあります。Mosa はしないので、手順 4 のように、画面では同じに見える 2 つの原子が、別の原子のことがあります。日本語入力で打った文字は、ふつうは符号位置 1 つの形です。ほかから写した文字は、2 つの形のことがあります。ほかのプログラムから写した事実が、自分で打った同じ言葉と合わないときは、`atom_length/2` や `atom_codes/2` で 2 つを比べてください。

全角記号モードでは、Mosa は次の全角の記号を半角の記号として読みます。

| 全角 | 読み方 |
| --- | --- |
| `（` `）` | `(` `)` |
| `［` `］` | `[` `]` |
| `，` `、` | `,` |
| `。` | 節や問い合わせの終わりの `.`。小数点にはならない |
| `：` | `:` |
| `「` `」` | 引用符で囲んだ原子の始まりと終わりの `'`。最初の `」` で原子が終わるので、入れ子にはできない |

ほかの全角の記号は変わりません。全角のピリオド `．` はエラーのままで、`3.14` の小数点は半角の `.` で書きます。プロンプトで設定したフラグは、また変えるか Mosa を終えるまで続きます。ファイルの中のディレクティブで設定したフラグは、そのファイルの終わりまで続きます。ディレクティブを書かずに全角の記号を使ったファイルは、読み込めません。そのときのメッセージを見てみます。次の 1 行を `全角だけ.pl` という名前でフォルダ `prolog` に保存し、シェルからそのファイル名を付けて `mosa` を起動します。第 4 章の `誤字.pl` のときと同じように、Mosa は 1 行目の 3 桁目の `（` で止まり、シェルに戻ります。

<!-- file: nodirective-file 全角だけ.pl -->
```prolog
首都（日本、東京）。
```

<!-- check: nodirective -->
```console
$ mosa 全角だけ.pl
全角だけ.pl:1:3: 予期しないトークン
```

Mosa のメッセージの言語は、Mosa を起動したときに決まります。環境変数 `LANG` は、シェルがどのプログラムにも渡す設定の一つです。`LANG` が `ja` で始まっていれば日本語、それ以外の値なら英語になります。`LANG` が設定されていないとき、Windows では Windows の表示言語（「設定」の「時刻と言語」）に従い、macOS と Linux では英語になります。macOS と Linux の端末は、ふつうシステムの言語に合わせて `LANG` を設定しています。値は `echo $LANG` と打って確かめられます。

<!-- skip: echo-lang -->
```console
$ echo $LANG
```

## 練習問題

1. `ありがとう` の文字をリストで尋ね、その数も尋ねてください。
2. `首都.pl` を読み込み、プロンプトで全角記号モードをオンにして、フランスの首都を全角の記号で尋ねてください。

### 答え

1. `atom_chars/2` でリストを作り、`length/2`（第 7 章）で数えます。

<!-- check: exercise-chars -->
```text
?- atom_chars(ありがとう, L), length(L, N).
L = [あ,り,が,と,う], N = 5.
```

2. `首都.pl` のディレクティブは、ファイルの中でしかモードを変えません。ですから、自分でオンにします。

<!-- check: exercise-capital -->
```text
?- consult('首都.pl').
true.
?- set_prolog_flag(japanese_punctuation, true).
true.
?- 首都（フランス、X）。
X = パリ.
```

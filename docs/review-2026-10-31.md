# Review of main, 2026-10-31

Five independent reviewers read main at f240e69 (execution core, memory and terms, builtins, reader/writer/I/O, loading/modules/mosac) and proved each finding with a query they ran. Items already listed in `docs/iso-notes.md` or in the Doubts/Open lines of `docs/STATUS.md` were left out. ✔ marks findings that were reproduced again before this file was written.

What held up: no program out of more than 40 behaved differently under `mosac` than in the interpreter; no missed or doubly visited GC root was found under `MOSA_GC_STRESS=1`; cut transparency, catch/throw, bagof/setof (8.10 Examples), the logical update view (7.5.4), the error order of functor/arg/univ/atom builtins, and the stream errors of 7.10/8.11 behaved as the standard says.

How to use this file: take one item per session (AGENTS.md). Items marked **decision** need an ADR or an "A or B?" question in `docs/iso-notes.md` before any code. When an item is done, change its status to `done (<commit>)`.

## High

### H1. End token followed by `%` is a syntax error ✔
- Status: done (b1f5739)
- Where: `src/read/lexer.cpp:234-246` (`layout_follows` only accepts layout characters)
- Repro: `open_string('a.% c\n',S), read(S,T)` gives `syntax_error(unexpected_token)`; expected `T = a`. A file containing `p.% comment` fails to consult as a whole; full-width mode `w（x）。% c` fails the same way.
- Standard: 6.4.8 (an end char is followed by a layout char or `%`).

### H2. `writeq(-(1^2))` writes `-1^2`, which reads back as `(-1)^2` ✔
- Status: open
- Where: `src/write/writer.cpp:609` (brackets decided only by "the operand is an unsigned number", not "the operand's text starts with a number")
- Repro: `writeq(-(1^2))` prints `-1^2`; `-(1**2)` likewise.
- Standard: 7.10.5, 6.3.4.1.

### H3. Deterministically finished `catch/3` and `*->` leave their Entry on the choice stack ✔ (decision)
- Status: open
- Where: `src/machine/catch.cpp:240-246` (`disarm_catch` only clears `armed`), `src/machine/engine.cpp:53-56` (SoftCommit only sets `cond_ok`)
- Repro: `lw(0) :- !. lw(N) :- catch(true,_,true), N1 is N-1, lw(N1).` stops at the heap limit with `--heap-max 8` and `lw(300000)`; without the catch, 1,000,000 passes. `(true *-> true ; true)` in the loop does the same. After a 100,000-step catch loop, a findall of 10,000 solutions takes 5,249 ms instead of 10 ms, because `has_more` (`engine.cpp:30`) walks the stack per solution.
- Expected: a deterministic exit leaves no choice point; memory and time do not grow.
- Decision: when the Entry can be removed (no choice point above it) — ADR 0011 or a new ADR.

### H4. Nested findall crashes at about 6,000 levels ✔ (decision)
- Status: open
- Where: `src/builtins/solutions.cpp:629` (findall runs `run_loop` by native recursion)
- Repro: `d(0,z) :- !. d(N,s(L)) :- N1 is N-1, findall(X, d(N1,X), [L]).` — `d(4000,_)` succeeds, `d(6000,_)` exits with SIGSEGV (rc 139, 8 MiB stack); bagof crashes at 10,000.
- Expected: no crash; at worst `resource_error` (7.12.2). iso-notes 7.1 covers only the reader.
- Decision: run nested collections without native recursion, or a depth limit with `resource_error` — ADR.

### H5. Asserting a clause whose whole body is a variable raises instantiation_error ✔ (decision)
- Status: open
- Where: `src/builtins/database.cpp:143-147`
- Repro: `asserta((p :- X))` and `assertz((p(X) :- X)), p(true)` raise `instantiation_error`; `asserta((p(X) :- true, X))` succeeds.
- Standard: 8.9.1.3 lists only a variable head; 7.6.2 converts a variable body to `call(X)`. The code comment says this is intended, but iso-notes and the tests do not record it.

### H6. A heap-limit stop inside with_output_to/2 or portray leaves current output redirected
- Status: open
- Where: `src/builtins/write_pred.cpp:699-712` (`run_with`), `:448-478` (`apply_portray`), `src/machine/session.cpp:162`
- Repro: `mosa --heap-max 16 -g 'with_output_to(atom(A),(write(hello),length(L,100000000)))'`, then `?- write(visible), nl.` prints only `true.`. With `portray(big) :- length(L,100000000).` and `print(f(big))`, the next `write(visible)` raises `existence_error(stream,'$stream'(3))` (the hook's destructor closed the stream that current output still names).
- Expected: `current_out` is restored on every exit path (RAII), and `recover_heap`/`query()` reset it.

## Medium

### M1. `-9223372036854775808` cannot be read ✔
- Status: open
- Where: the reader's integer token (range checked before the sign is applied); `atoms_number.cpp:190` special-cases it for number_codes only
- Repro: `read` of `-9223372036854775808.` gives `syntax_error(integer_overflow)`; `writeq` of `min_integer` therefore does not read back, and a file with that literal fails under mosa and mosac.
- Standard: 6.3.4.1 (`-` followed by a numeric literal is a negative constant), 7.10.5.

### M2. A float literal out of range silently becomes `inf.0` ✔ (decision)
- Status: open
- Where: `src/read/lexer_literal.cpp:257-259`
- Repro: `X = 1.0e400` and `number_codes(X,"1.0e400")` give `inf.0`; `X is 1.0e400 * 1` does not raise although `float_overflow=error`; `number_codes(Y,"inf.0")` is a syntax error, so 8.16.8 round-trip fails.
- Decision: `syntax_error` (like integer overflow) or `evaluation_error(float_overflow)`.

### M3. First-argument indexing scans every clause on each call (decision)
- Status: open
- Where: `src/machine/index.cpp:40-55`; `src/machine/choice.cpp:220,282` (`const Entry top = machine.stack.back();` copies `candidates`)
- Repro: `(p(_,_), fail ; true)`: 25,000 clauses 174 ms, 50,000 701 ms, 100,000 2,643 ms. Looking up 20,000 clauses by every key: 1,269 ms (5,000: 82 ms). `retract(p(N,_))` 20,000 times: 12 s.
- Expected: SPEC section 6 promises first-argument indexing; time should be linear.
- Decision: index structure and its update on assert/retract — ADR.

### M4. op/3 changes are undone on backtracking, on exceptions and after findall (decision)
- Status: open
- Where: `src/machine/choice.cpp:286`, `src/machine/catch.cpp:197`
- Repro: after `findall(x, op(700,xfx,qq2), _)`, `current_op(_,_,qq2)` fails; `forall(m(O,[aa,bb]), op(700,xfx,O))` leaves nothing defined. assertz, set_prolog_flag and char_conversion are not undone.
- Standard: 8.14.3 makes op/3 a side effect and does not undo it. Not recorded in iso-notes; the Logtalk test `iso_op_3_20` it was based on passes either way (comment in `tests/pl/operators.pl`).

### M5. open/3 for writing empties the file at open and writes only at close or flush
- Status: open
- Where: `src/builtins/streams.cpp:96-99, 431-444`
- Repro: `open(F,write,W), write(W,kept), close(W), open(F,write,S), write(S,lost)` and `-t halt`: F is 0 bytes (old and new contents lost). Also with `halt` inside `-g`.
- Expected: output reaches the file without an explicit close; halt flushes open streams.

### M6. findall/bagof keep solutions outside the heap, so `--heap-max` does not bound them
- Status: open
- Where: `src/builtins/solutions.cpp:611-650` (`ExportedTerm`/`Image`)
- Repro: `--heap-max 16 -g "findall(f(X,X,X), between(1,10000000,X), L)"` reaches 3.6 GB RSS and stops after 12.7 s.
- Expected: ADR 0010 says the limit stops the machine before the OOM killer does.

### M7. Cyclic terms hang or grow without bound in ground/1, assert and =..
- Status: open
- Where: `src/builtins/types.cpp:68-84` (`ground_term`), `src/machine/compile.cpp:299` (`compile_goal`/`compile_clause`), `=..`
- Repro (`--heap-max 16`): `X=f(X), ground(X)` does not return; `X=f(X,X), ground(X)` 7.7 GB; `X=(a,X), assertz((p:-X))` 11.6 GB; `X=[a|X], T=..[f|X]` does not return.
- Expected: terminate (other builtins give `type_error(list,…)` or handle cycles).

### M8. In full-width mode writeq does not quote `、` `：` `（`
- Status: open
- Where: the writer's quoting decision
- Repro: with `japanese_punctuation=true`, `writeq(f('、'))` prints `f(、)`, which does not read back; `'：'(a)` comes out as `:(a)`, `'、'(a,b)` as `(a,b)`; `'（'` breaks; `「` is quoted correctly.
- Standard: SPEC section 4, 7.10.5.

### M9. variable_names/1 can give two different variables the same name
- Status: open
- Where: `src/write/writer.cpp:443-445`
- Repro: `write_term(f(A,B),[variable_names(['_G1'=A])])` prints `f(_G1,_G1)`.
- Standard: 7.10.4.

### M10. consult accepts clauses for builtins and control constructs, and non-callable bodies (decision)
- Status: open
- Where: `src/machine/load.cpp` (`take_term` → `add_clause`)
- Repro: a file with `atom_length(_,99).`, `call(_) :- write(mine).` and `foo :- 1.` loads without error under mosa and mosac; `atom_length(abc,L)` still gives 3, `current_predicate(atom_length/2)` is true, and `foo` raises `type_error(callable,1)` only when called (context `call/1`). assertz/1 raises permission_error and type_error for the same clauses.
- Decision: the error and whether loading continues (7.4.2 / 7.5).

### M11. Stage G predicates of SPEC are not implemented (decision)
- Status: open
- Where: `docs/SPEC.md:305`
- Repro: `tab/1`, `term_to_atom/2`, `nb_setval/2`, `setup_call_cleanup/3`, `sort/4`, `numbervars/3` raise existence_error; none exists in `src` or `lib`. iso-notes covers only forall/2 and sort/2.
- Decision: which phase they belong to.

## Low

### L1. Integer edge cases in rem, mod, gcd, max and min
- Status: open
- Where: `src/builtins/arith.cpp:256-259, 385-390`
- Repro: with `M is -9223372036854775807-1`, `M rem -1` and `M mod -1` raise int_overflow (the value is 0); `gcd(M, 2)` raises int_overflow (value 2) and computes `-args[0].ival` before the check (signed overflow, undefined behavior). `max(9007199254740993, 9007199254740992.0)` returns `9.007199254740992e+15`, smaller than the integer argument.
- Standard: 9.1.3, 7.9.2.

### L2. `-0.0 == 0.0` holds, so sort/2 drops one; `sign(nan)` is 1.0; `integer(2.5)` is 2 (decision)
- Status: open
- Where: comparison and unification of floats; `src/builtins/arith_float.cpp:60`
- Repro: `-0.0 == 0.0` succeeds; `sort([0.0,-0.0],L)` gives `[0.0]`; writeq and copysign tell them apart. `sign(nan)` gives 1.0. `integer(2.5)` gives 2 (truncation).
- Decision: ISO does not say; record the choice in iso-notes.

### L3. Cyclic elements and occurs check

- Status: open

### L8. Windows stdin and stdout are in text mode (not verified)

- Note: `_setmode` to binary is not called, so CRLF translation and 0x1A in a pipe may end input. Needs a check on Windows.

### L9. mosac fails on trigraph-like text under `MOSA_WERROR=1`

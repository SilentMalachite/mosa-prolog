# main のレビュー（2026-10-31）

f240e69 の main を、5 人のレビュアーが独立に読んだ（実行の中核、メモリと項、組込、reader・writer・入出力、読み込み・モジュール・mosac）。指摘はどれも、実際に動かしたクエリで裏付けてある。`docs/iso-notes.md` と `docs/STATUS.md` の Doubts・Open に載っている項目は除いた。✔ は、このファイルを書く前にもう一度再現を確かめた指摘である。

問題がなかったもの: 40 本を超えるプログラムのどれも、`mosac` で訳したときとインタプリタとで動きが食い違わなかった。`MOSA_GC_STRESS=1` で、取りこぼしたルートや二度訪ねるルートは見つからなかった。カットの透過、catch/throw、bagof/setof（8.10 の Examples）、論理的更新ビュー（7.5.4）、functor・arg・univ・アトムの組込の誤りの順、7.10 と 8.11 のストリームの誤りは、規格どおりに動いた。

使い方: 1 セッションで 1 項目を扱う（AGENTS.md）。**判断** と付けた項目は、コードを書く前に ADR か、`docs/iso-notes.md` に「A か B か」の問いを書く。済んだら状態を `done (<コミット>)` に変える。

状態: 承認済み（2026-10-27）。フェーズ4のモジュール設計の承認を兼ねる。

## 背景

フェーズ4では、二つのモジュールが同じ名前とアリティを定義できる。探索は名前とアリティだけの一つのベクタである。
呼び出し中のモジュールは後戻りで戻る。Cell とフェーズ2のゴール枠は変えない。

## 決定

述語の識別は（モジュール、名前、アリティ）である。Predicate.home がモジュールのアトムである。組込はディスパッチ表のままで、system モジュールである。
呼び出し中のモジュールは Impl.calling である。選択点がやり直し用に記録し、節が成功したときに制御枠が戻す。
探索は呼び出し元の名前空間、その既定の取り込み元、system の順である。user の既定は system、それ以外の既定は user である。

## 捨てた案

名前とアリティだけの一つの表。二つのモジュールが parent/2 を同時に持てない。
呼び出し中のモジュールを Cell かフェーズ2のゴール枠に入れる案。ADR 0001 か ADR 0003 を変えてしまう。
インタプリタの中でインポートを直接呼び出しに解決する案。その解決はフェーズ6の仕事である。

## 影響

探索と追加はモジュールを取る。失敗した読み込みは、節と一緒にモジュールの記録を戻す。
翻訳器がインポートを解決するのは、これまでどおりフェーズ6である。この識別を変えるには新しい ADR が要る。

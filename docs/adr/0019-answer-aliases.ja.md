## 背景

`format_answer` は、値が前の束縛に出た未束縛の変数である束縛を書かない。書き手は名前の付いた変数を、束縛を辿らずにその名前で書く（レビュー M26）。
そのため名前が消え（`X = Y, Y = Z.` は `X = Z.` と答え、`findall(f(X)-X, true, [Y-P]).` は P を示さない）、1 つの変数が 2 つの字面になる（`findall(X-X, true, [P-Q]), Y = g(Q).` は `P = _G1, Y = g(Q)` と答える）。
所有者は、それぞれに作った名前を書く B ではなく、別名を示す A を選んだ。

## 決定

値が同じ未束縛の変数である名前は、束縛の順に 1 つの組をなす。2 つ以上の名前 N1 … Nk の組は、前の束縛が何を示したかによらず、N1 … Nk-1 の場所に `N1 = N2, N2 = N3, …` と鎖で示す。問い合わせのどの変数そのものでもない変数は、ほかの値の中で Nk と書く。
名前が 1 つの組で、変数がその問い合わせの変数そのものなら、これまでどおり前の束縛が示していなければ `N = N` と示す。それ以外の名前が 1 つの組は必ず示す（`P = _G1`）。作った名前からは、その変数がどの名前のものか分からないからである。
束縛された値はこれまでどおり書き、値の等しい束縛はまとめない（`X = f(A), Y = f(A)`）。

## 退けた案

B、変数のどの名前にも作った名前を書く（`X = _G1, Y = _G1, Z = _G1`）: 利用者が付けた名前が隠れ、書き手は名前の付いた変数をその名前で書くのをやめなければならない。
束縛された値もまとめる（`X = Y, Y = f(A)`）: 値をすべての組で比べることになり、M26 に関わらない答えも変わる。
新しい変数を N1 と書く: 鎖が名前の等しさを示すので正しさは同じだが、鎖は Nk で終わる（`P = Q, Y = f(Q)`）。問い合わせの変数そのもののセルを持つ値は、どちらでもその名前のまま（`Y = g(Q)`）。

## 帰結

`X = Y, Y = Z.` は `X = Y, Y = Z.`、`Y = Z, X = Y.` は `Y = Z, Z = X.`、`findall(X-X, true, [P-Q]), Y = g(Q).` は `X = X, P = Q, Y = g(Q).`、`findall(f(X)-X, true, [Y-P]).` は `X = X, Y = f(_G1), P = _G1.` と答える。答えを貼り直すと同じ共有になる。
変わるのは名前を落としていた答えだけである: `functor(T, f, 2), arg(1, T, A).` は `A = _G1` も示すようになり、`X = Y`、`X = f(Y)`、`Y = _G1, Z = [E|_G1]` は変わらない。翻訳したコードも同じ `format_answer` で答えを書く。
REPL は読んだゴールを、`char_conversion` が `_` を変えない限り `_` を `_` のまま書く（レビュー L18）。名前の無い変数は答えの名前にならず、`_G1 = _G2` も足さない: `f(_, X) = f(a, b).` は `X = b.` と答える。mosatest の `solutions` は変えない。テスト: tests/cpp/session_test.cpp の `check_answer_aliases`。

## 背景

7.5.4 は、呼び出しは呼んだ時点にあった節に対して働くと言い、持ち主はその読みを選んだ（iso-notes 7.5.4 の決定 B）。
ADR 0004 は、retract した節を Predicate::clauses から消して開いている選択点からも外し、abolish はその述語の開いている走査をすべて空にする。
走査の候補の並びは呼んだ時点の節をすでに固定しているので、`assertz/1` はもう論理的である。見え方を崩すのは取り除く側だけである。

## 決定

retract、retractall、abolish は、開いている走査（呼び出し、clause/2、retract）がまだ試していない候補にその節を持つあいだは、節を消さずに死んだ印を付ける。そうでなければ今どおり消す。
新しい呼び出し、clause/2、retract、節の数は死んだ節を飛ばし、開いている走査は試す。開いている走査があるときの abolish は述語にも消した印を付け、新しい引き当てはどれも無いものとして扱う。
死んだ節と消した印の述語は、その述語への次の変更のときに、それを持つ開いた走査が無ければ消す。ADR 0004 の残り（1 本のベクタ、asserta の添字ずらし、見せる前の IR 化）はそのままである。

## 捨てた案

節を共有ポインタの裏に置き、走査ごとに自分の写しを持たせる案。compile と codegen が読む置き場の形が変わる。
すべての節と選択点に世代番号を持たせる案。候補の並びが呼んだ時点の集合をすでに固定しているので、番号は何も足さない。
ADR 0004 のままにする案。logical update の 4 件が不合格のまま残り、持ち主の決定に反する。

## 影響

ADR 0004 の retract と abolish の文はこの ADR で置き換え、この ADR の承認後に 0004 の状態の行にそう書く。
Clause と Predicate に印を 1 つずつ足す。節を数えたり並べたりする所（number_of_clauses、listing、enter_user の空の判定、テスト用の機械への写し）は生きている節だけを使う。
`tests/pl/database.pl` の `retract_open_later` は、実装のコミットで `[X = 1, X = 2, X = 3]` に変える。承認までコードは書かない。

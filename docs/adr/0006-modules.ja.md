状態: 承認済み（2026-10-28）。制御フレームの 1 語目が extras の添字であるという文は、[ADR 0009](0009-native-code.ja.md) で 1 語目の第 63 ビットが立っていないフレームに狭めた（2026-10-29）。改訂 1（2026-11-06、レビュー L19 の A1、所有者の決定 A。A を実装する選択で承認）: `library(...)` で読むファイルは、`user` の表の代わりに ISO の核で読む

## 背景

フェーズ4で SPEC 第5節のモジュール系を足す。今の述語は (名前, アリティ) だけで引かれ、ゴールフレームはどのモジュールで動くかを持たない。
`Module:Goal`、`meta_predicate/1` の引数、限定のない `assertz/1` は、実行時に文脈モジュールが要る。
フェーズ6の `mosac` も同じゴールフレームを生成する（ADR 0003）ので、コードより先に形を決める。

## 決定

Predicate にモジュール（モジュール名の原子番号）を持たせ、鍵を (モジュール, 名前, アリティ) にする。`system` は C++ の組み込みと制御構文を持ち、`user` は既定のモジュールである。
ゴールフレーム（0 語目が 0 でない）の 1 語目は、ビット 0〜15 がアリティ、ビット 16〜47 が文脈モジュールの原子番号である。kFrameHead は 4 のままで、IR は変えない。本体のゴールは、その節の述語のモジュールを受け継ぐ。切り替えるのは `M:G` と `meta_predicate/1` の引数だけである。
引く順は `system` が先（`system` の名前を定義すると `permission_error(modify, static_procedure, PI)`）、次に文脈モジュールの定義と取り込み、最後にその既定の取り込み元である。演算子はモジュール固有、`user`、ISO の核の順に引く。公開リストの `op/3` は取り込み側の固有層に入る。

## 捨てた案

すべてのゴールフレームに 5 語目を足す案。アリティの語に収まる値のために、全フレームが 1 語太る。
節を読み込むときに述語を解決し、その番号をフレームに入れる案。後から定義した述語や assert した述語が見えない。
演算子の表を全体で 1 つにする案。SPEC 第5節は `op/3` を宣言したモジュールに閉じると決めている。

## 影響

制御フレーム（0 語目が 0）の 1 語目は、今どおり extras の添字である。ゴールフレームの 1 語目の読み書きは、すべて `read_goal` と `write_goal` を通す。
フェーズ6の `mosac` は同じビットに文脈モジュールを書く。フェーズ7の GC はこの語を項として走査しない。
Reader と Writer は OperatorTable ではなく演算子の見え方を受け取る。この ADR が承認されるまで、モジュールのコードは書かない。

## 改訂 1（2026-11-06、レビュー L19 の A1、所有者の決定 A）

背景: `user` の演算子はどのモジュールからも見えるので、`op(1100, xfy, ->)`（8.14.3）の後に読んだライブラリのファイルは、構文エラーにならずに別の節に読まれうる。レビュー L19 で `format.pl` がそう読まれ、その後のメッセージがどれも鍵の形に落ちた。
決定: `use_module(library(Name))` が見つけたファイル（同梱か探索のパス上か。そのファイルが読むファイルを含む）を読む間は、`user` の表を退けて ISO の核を置く。だからファイルは ISO の核と自分のモジュールの層で読まれる。読み込みの間の `user:op/3` は、ISO の核と退けた `user` の表の両方へその場で入り、どちらかが拒否すればパスで読むときと同じく拒否される。読み終えると、その変更を持った `user` の表を戻す。断られた読み込みは、表を入る前の形に戻す。実行時は何も変わらない。項を読み書きするライブラリの述語（format/2 の `~q`）は今までどおり `user` の演算子を見る。
捨てた案: B（既知の制限のままにする）は、そうした op/3 の後でライブラリの述語が黙って誤る。ライブラリのモジュールに印を付け、その見え方がいつも ISO の核を使うようにする案は、`~q` が利用者の項を利用者の演算子なしで書く。メッセージのためだけにライブラリを読み直す案は、プログラムの使う方が誤って読まれたまま残る。影響: SPEC 第5節の「`user` で宣言した演算子は全モジュールに見える」は、ライブラリのファイルを読む間は成り立たない。演算子の要るライブラリは、自分のモジュールで宣言するか公開する。`library(...)` でなくパスで読むファイルは、今までどおり `user` の表で読む。

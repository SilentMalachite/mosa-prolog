Benchmark programs. Each defines `bench(N)` as a failure-driven loop and checks its first solution; `mosatest --bench <file>` measures it in the interpreter and in the `mosac` output, and the results go to `docs/bench.md` as a table and to `docs/bench.json`. The six programs are `nrev`, `queens`, `zebra`, `tak`, `deriv` and `crypt`; `tests/pl/bench_<name>.pl` includes each one so that its first-solution check also runs in `mosatest tests/pl` and in the differential test.

ベンチマークのプログラム。どれも `bench(N)` を失敗駆動の繰り返しで定義し、最初の解を確かめる。`mosatest --bench <ファイル>` がインタプリタと `mosac` の変換物で測り、結果は `docs/bench.md` に表で、`docs/bench.json` に記録する。6 本は `nrev`、`queens`、`zebra`、`tak`、`deriv`、`crypt` である。`tests/pl/bench_<名前>.pl` がそれぞれを include し、最初の解の確かめを `mosatest tests/pl` と差分テストでも流す。
